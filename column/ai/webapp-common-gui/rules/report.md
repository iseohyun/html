# 보고서

읽는 문서이면서 발표 자료로도 쓰는 페이지의 형식입니다. 본문을 **슬라이드** 와 **스크립트** 의 짝으로 씁니다. 슬라이드는 16:9 화면에 띄울 요약이고, 스크립트는 그 슬라이드를 말로 풀어 주는 글입니다.

화면 틀(레일, 패널, 헤더, 탭)은 [「화면」 규칙](#/column/ai/webapp-common-gui/rules/screen.md)를 그대로 따릅니다. 이 문서는 본문 영역 안의 규칙만 정합니다.

## 구성

```text
ReportPage                 탭 하나 = 장 하나
└─ Block                   묶음 하나 = 주제 하나. 목차에 묶음 제목이 나옴
   ├─ SlideFrame           전체 화면 단추와 쪽 번호가 붙는 자리
   │  └─ Slide             16:9
   │     ├─ 머리           작은 글씨 한 줄(문서 · 장), 슬라이드 제목
   │     ├─ 요약 목록      개조식 서너 줄. 위쪽
   │     └─ 아래 줄        그림과 범례. 아래쪽
   └─ Script               평서문 문단. 슬라이드 바로 아래
```

- 묶음 하나에 슬라이드 하나, 스크립트 하나를 둡니다. 슬라이드 없이 스크립트만 길게 쓰지 않습니다.
- 한 탭에 묶음을 여러 개 둘 수 있고, 위에서 아래로 읽는 순서가 곧 발표 순서입니다.

## 슬라이드

| 항목 | 규칙 |
| :--- | :--- |
| 비율 | 16:9로 고정. 본문 폭에 맞춰 줄고 늘며, 최대 폭은 60rem. |
| 바탕 | 표면(`--surface`)에 선(`--line`) 테두리, 모서리는 큰 단계(`--r-lg`). |
| 크기 단위 | 슬라이드 안의 글자·여백·간격은 모두 슬라이드 폭에 비례하게 잡습니다(`cqw`). 본문에서 작게 보일 때와 전체 화면에서 크게 보일 때의 배치가 같아야 합니다. |
| 글자 크기 | 기준 글자는 슬라이드 폭의 1.6%. 폭 940px에서 약 15px, 1920px 전체 화면에서 약 31px. 제목은 기준의 1.75배. |
| 넘침 | 내용이 슬라이드를 넘치면 글자를 줄이지 않고 내용을 덜어 내거나 슬라이드를 나눕니다. 슬라이드 안에서는 스크롤하지 않습니다. |

### 슬라이드 안의 배치

| 자리 | 넣는 것 | 규칙 |
| :--- | :--- | :--- |
| 위 | 요약 목록 | 그 슬라이드에서 말할 것을 서너 줄로. 각 줄은 「**낱말**: 내용」 꼴로 시작해 한눈에 훑을 수 있게 합니다. |
| 아래 | 그림 | 그래프, 도식, 흐름. 슬라이드 바닥에 붙입니다. |
| 그림 옆 | 범례 | 그림을 읽는 데 필요한 표는 따로 두지 않고 범례로 넣습니다. 이름, 값, 한 줄 설명을 줄마다 나란히 놓고, 표식(색 칸, 선 모양)의 뜻은 그 아래에 둡니다. |

- 표의 선과 머리 줄은 그리지 않습니다. 범례는 표가 아니라 그림에 딸린 설명입니다.
- 그림 없이 흐름이나 단계만 보여 줄 때는 아래 줄에 단계 칸을 가로로 나열합니다.
- 그림의 색도 역할 토큰만 씁니다. 강조할 부분은 글자색(`--fg`)으로 채우고, 나머지는 선택 면(`--active`)으로 둡니다.

### 주제 슬라이드

장의 끝에는 그 장의 결론을 한 장으로 따로 둡니다. 위의 「요약 위, 그림 아래」 배치를 쓰지 않고, 주제 한 줄을 부각하며 지면을 넉넉하게 씁니다.

| 자리 | 넣는 것 | 규칙 |
| :--- | :--- | :--- |
| 가운데 | 주제 한 줄 | 슬라이드의 제목 자리를 겸합니다. 기준 글자의 4배, 두 줄을 넘기지 않습니다. 위에 흐린 글씨로 짧은 머리말(누구에게, 무엇에 대한 것인지)을 한 줄 둘 수 있습니다. |
| 아래 | 받침 세 가지 | 선 하나로 구분한 뒤 세 칸으로 나란히. 칸마다 굵은 낱말 하나와 흐린 설명 한 줄. 세 개를 넘기지 않습니다. |
| 여백 | | 좌우 안쪽 여백을 다른 슬라이드의 1.5배로 넓히고, 그림과 범례는 넣지 않습니다. |

- 스크립트는 「결론입니다.」처럼 결론임을 밝히는 문장으로 시작해 받침 세 가지를 먼저 말하고, 주제 문장을 맨 뒤에 둡니다. 주제 문장 하나만 하이라이트합니다.
- 슬라이드 짚기는 받침 세 가지에 차례로 체크, 마지막에 주제 한 줄에 밑줄을 씁니다.

## 글투

| 자리 | 글투 | 예 |
| :--- | :--- | :--- |
| 슬라이드 | 개조식. 명사나 명사형으로 끝내고 마침표를 찍지 않습니다. | 쓸모가 증명된 것을 빠르게 도입 |
| 스크립트 | 경어를 쓰는 평서문. | 쓸모가 증명된 것을 초기 다수보다 먼저 가져갑니다. |

- 스크립트에는 표와 목록을 쓰지 않습니다. 슬라이드의 범례에 넣은 내용도 스크립트에서는 문장으로 풀어 씁니다.
- 스크립트의 문단은 슬라이드의 요약 목록과 같은 순서로 씁니다.
- 꼭 짚어야 하는 문장만 하이라이트합니다. 문장 단위로 표시하고, 묶음 하나에 한두 문장을 넘기지 않습니다. 표시는 `<mark>`에 `--mark` 면과 굵은 글씨입니다.
- 출처와 날짜는 스크립트 맨 아래에 흐린 고정폭 글씨 한 줄로 적습니다.
- 스크립트 글자는 본문보다 조금 작게(0.9rem), 줄 간격은 넉넉하게(1.8) 잡고, 폭은 긴 글의 폭(약 52rem)을 따릅니다.

## 전체 화면 보기

슬라이드마다 전체 화면으로 볼 수 있습니다.

| 항목 | 규칙 |
| :--- | :--- |
| 단추 | 슬라이드 오른쪽 위 모서리에 테두리 없는 아이콘 단추. 아이콘은 공통 아이콘의 「전체 화면」(`i-frame`). 열려 있는 동안에는 「닫기」(`i-x`)로 바뀝니다. |
| 단추 줄 | 오른쪽 위에 왼쪽부터 **자막 · 읽기 설정 · 스피커 · 닫기**. 자막과 읽기 설정 단추는 전체 화면에서만 보입니다. 단추 사이는 4px, 크기는 모두 32px. |
| 읽기 설정 창 | 전체 화면에서는 헤더가 보이지 않으므로, 읽기 설정 단추(`i-gear`)가 단추 줄 아래에 창을 엽니다. 내용은 헤더 설정의 읽기 줄과 같은 것이고(같은 컨트롤을 옮겨 와 씁니다), Esc나 단추로 닫습니다. 창 안에서 누른 키는 슬라이드를 넘기지 않습니다. |
| 설정 창의 구현 | 브라우저의 popover(`<dialog popover="auto">`)로 띄웁니다. 위층(top layer)에 뜨므로 겹침 순서(z-index)를 따로 두지 않고, 창 밖을 누르거나 Esc를 누르면 닫힙니다. 읽기 설정 단추는 `popovertarget`으로 창과 이어 두어, 다시 누르면 닫힙니다. 자리는 열 때 단추의 위치를 재서 그 아래로 정합니다. 닫힌 창에는 `display`를 주지 않습니다(닫힌 popover가 보이지 않게). |
| 보이는 것 | 고른 슬라이드 하나만. 화면에 16:9로 가득 맞추고 남는 자리는 바탕(`--bg`)으로 둡니다. 스크립트, 헤더, 사이드바는 보이지 않습니다. 테마는 그대로 따릅니다. |
| 넘기기 | 같은 탭의 슬라이드끼리 넘깁니다. 다음은 PageDown, 이전은 PageUp. 읽지 않는 동안에는 → ↓ 와 ← ↑ 도 같은 일을 합니다. 첫 장과 끝 장에서는 더 가지 않습니다. 키 전체는 아래 「슬라이드 보기의 키」. |
| 쪽 번호 | 오른쪽 아래에 「지금 / 전체」를 흐린 고정폭 글씨로. 전체 화면에서만 보입니다. |
| 닫기 | Esc 또는 단추. 닫으면 본문에서 마지막에 보던 슬라이드 자리로 돌아갑니다. |
| 단축키 | 전체 화면 동안에는 슬라이드 보기의 키와 닫기(Esc)만 받고, 화면 틀의 다른 단축키(M, F 등)는 받지 않습니다. |
| 막힌 환경 | 브라우저의 전체 화면 기능을 쓸 수 없으면(미리보기 프레임 등) 창 안을 가득 채우는 것으로 대신하고, 콘솔에 이유를 남깁니다. |
| 열자마자 닫을 때 | 브라우저의 전체 화면이 열리기 전에 닫으면(열자마자 Esc), 뒤늦게 열린 전체 화면을 도로 닫습니다. 슬라이드 표시는 닫혔는데 브라우저만 전체 화면으로 남지 않게 합니다. |

## 슬라이드 보기의 키

본문 화면과 전체 화면에서 같은 키를 씁니다. 입력 칸에 글자를 넣는 중에는 받지 않습니다.

| 키 | 하는 일 |
| --- | --- |
| 스페이스 | 재생과 멈춤. 멈춘 자리에서 이어 읽습니다. 이어 재생을 듣던 중이었거나 아직 아무것도 듣지 않았으면 이어 재생으로, 슬라이드 하나만 듣던 중이었으면 그 슬라이드만 읽습니다. 단추나 링크에 초점이 있으면 본문 화면에서는 그 요소를 누르는 키로 남습니다. |
| PageDown · PageUp | 다음 · 이전 슬라이드. 읽는 중이면 옮겨 간 슬라이드의 처음부터 이어 읽고, 멈춰 있으면 화면만 옮깁니다. |
| → · ← | 읽는 중에는 다음 · 이전 문장(음성). 슬라이드의 끝 문장에서 →를 누르면 다음 슬라이드의 첫 문장으로, 첫 문장에서 ←를 누르면 앞 슬라이드의 끝 문장으로 이어집니다. 읽지 않는 전체 화면에서는 슬라이드를 넘깁니다. |
| C | 자막 켜기와 끄기. 읽는 중이든 멈춰 있든 받습니다. |
| + · - | 읽는 속도를 25%p씩 올리고 내립니다(50% ~ 300%). Shift 없이 누르는 `=`도 +로 받습니다. 읽는 중이면 지금 문장을 새 속도로 처음부터 다시 읽고, 바뀐 값을 화면 위쪽에 잠깐 띄웁니다. 끝에 닿으면 「최대」·「최소」를 띄웁니다. |
| Esc | 전체 화면에서는 닫기, 본문 화면에서는 읽기 멈춤. |

## 읽어 주기

슬라이드마다 스크립트를 소리로 읽어 줍니다. 읽는 동안 스크립트에는 읽는 곳을 표시하고, 슬라이드에서는 그 문장이 말하는 곳을 짚습니다.

| 항목 | 규칙 |
| :--- | :--- |
| 단추 | 전체 화면 단추의 바로 왼쪽에 테두리 없는 아이콘 단추. 아이콘은 공통 아이콘의 「스피커」(`i-vol`). 다시 누르면 멈춥니다. |
| 읽는 중의 단추 | 그림이 「재생」(`i-play`)으로 바뀌고 글자색으로 채운 모양이 됩니다. 바탕이 글자색(`--fg`)과 흐린 글자색(`--muted`) 사이를 1.8초 주기로 천천히 오가며 읽는 중임을 알립니다. 동작 줄이기를 켠 사용자에게는 채운 모양만 보여 줍니다. |
| 읽는 것 | 그 슬라이드와 짝인 스크립트를 문장 순서대로. 출처와 날짜 줄은 읽지 않습니다. 문장은 마침표·물음표·느낌표에서 끊습니다. |
| 바꿔 읽는 낱말 | 목소리가 한 글자씩 끊어 읽거나 엉뚱하게 읽는 낱말은 도메인별 발음 사전대로 읽습니다(이 사이트는 `modules/features/say-words.json`). 사전은 `common`(모든 문서)과 도메인 묶음(예: 개발 `dev` — Javascript → 자바스크립트, json → 제이슨, F1 → 펑션일)으로 나누고, 문서가 쓰는 도메인은 경로 규칙(예: `/web-tech/` → `dev`)으로 정하되 문서 상자의 `data-say-domain`이 있으면 그것을 씁니다. 낱말은 앞뒤에 영문자가 없을 때만 대소문자를 가리지 않고 바꾸고(숫자는 붙어도 됨: 8bit → 8빗), 띄어 쓴 낱말(caps lock)도 받습니다. 겹치면 긴 낱말이 먼저입니다. 기호(`\`, `&&` 등)는 `<code>` 안에서만 바꿉니다. 화면의 글자와 자막은 그대로 두고, 단어 짚기는 원래 낱말을 짚습니다. 문장마다 다르게 읽어야 하면 스크립트에 `data-say`를 씁니다. |
| 전체 화면에서 | 단추가 그대로 보이고 읽습니다. 스크립트는 보이지 않고, 슬라이드 짚기만 보입니다. |
| 멈추는 때 | 단추를 다시 누를 때, Esc, 다른 슬라이드를 읽기 시작할 때, 전체 화면에서 슬라이드를 넘길 때, 탭을 바꿀 때, 끝까지 읽었을 때. |
| 기능이 없을 때 | 브라우저에 읽어 주기 기능이 없으면 단추와 읽기 설정을 넣지 않고 콘솔에 이유를 남깁니다. |

### 읽기 설정

헤더의 톱니 아이콘(화면별 설정)에 세 줄을 둡니다. 값은 다른 설정과 함께 브라우저에 기억합니다.

| 설정 | 값 | 규칙 |
| :--- | :--- | :--- |
| 목소리 | 자동(기본), 기기에 있는 목소리 목록 | 자동은 아래 「목소리를 고르는 순서」를 따르고, 고른 결과를 「자동 · 목소리 이름」으로 보여 줍니다. 목록은 문서 언어의 목소리를 위에 놓습니다. 기억해 둔 목소리가 기기에 없으면 자동으로 읽습니다. |
| 읽는 속도 | 50% ~ 300%, 기본 150% | 슬라이더로 고릅니다. 모양은 아래 「슬라이더」. 읽는 중에 바꾸면 다음 문장부터 적용합니다. 키(+ · -)로 바꾸면 지금 문장부터 적용합니다. |
| 읽는 곳 | 문단 · 문장 · 단어(기본) | 읽는 중에 바꾸면 바로 적용합니다. |
| 짚는 색 | 빨강(기본) · 주황 · 초록 · 파랑 · 직접 고르기 | 슬라이드 짚기의 밑줄·테두리·체크에 쓰는 색. 아래 「슬라이드 짚기」. |
| 자막 | 보기(기본) · 끄기, 위 · 아래(기본), 왼쪽 · 가운데(기본) · 오른쪽 | 아래 「자막」. |
| 자막 모양 | 배경색(기본 검정), 불투명도 0 ~ 100%(기본 30%), 흐림 0 ~ 20px(기본 4px), 글자 크기 50 ~ 200%(기본 100%) | 아래 「자막」. 불투명도는 5%씩, 흐림은 1px씩, 글자 크기는 10%씩 움직이는 슬라이더이고 자석 지점은 두지 않습니다. 흐림 0은 흐리지 않음. 글자 크기 100%가 화면 폭의 2.1%입니다. |
| 슬라이드 색 | 5칸 미리보기 · 고르기 · 기본값(기본) | 슬라이드 그림에 입히는 5×3 팔레트. 아래 「슬라이드 색」. |

| 읽는 곳 | 표시 |
| :--- | :--- |
| 문단 | 읽는 문장이 든 문단 전체를 선택 면(`--active`)으로 채웁니다. |
| 문장 | 읽는 문장만 선택 면으로 채웁니다. |
| 단어 | 문장을 선택 면으로 채운 위에, 지금 읽는 단어를 글자색(`--fg`) 면에 바탕색 글자로 뒤집습니다. 목소리가 단어 위치를 알려 주지 않으면(온라인 목소리 등) 재어 둔 빠르기로 어림해 단어를 넘기고, 문장이 끝나는 신호에서 다시 맞춥니다. 아래 「읽는 빠르기 재기」. |

#### 읽는 빠르기 재기

목소리마다, 속도마다 실제로 읽는 빠르기가 다릅니다. 문장 하나를 다 읽을 때마다 걸린 시간을 재서 기억해 두고, 다음 문장부터 그 값으로 어림합니다.

| 항목 | 규칙 |
| :--- | :--- |
| 재는 것 | 문장의 길이(낱말마다 글자 수 + 1, 쉼표로 끝나는 낱말은 2를 더함)와 읽는 데 걸린 시간. 길이 하나에 드는 시간을 구합니다. |
| 기억하는 단위 | 목소리와 읽는 속도의 짝마다 하나. 새로 잰 값을 6, 앞의 값을 4의 비율로 섞어 고칩니다. 설정과 별도 키로 브라우저에 기억합니다. |
| 처음 | 잰 적이 없는 짝은 100% 속도에서 1초에 8글자로 어림합니다. 첫 문장은 어긋날 수 있고 둘째 문장부터 맞습니다. |
| 쓰는 곳 | 단어 위치를 알려 주지 않는 목소리의 단어 넘기기, 진행 막대가 문장 안에서 움직이는 빠르기. |
| 진짜 신호가 있을 때 | 목소리가 단어 위치를 알려 주면 그 신호를 쓰고 어림은 그만둡니다. |

#### 목소리를 고르는 순서

「자동」일 때는 아래 순서로 찾아, 처음 있는 것을 씁니다. 글꼴을 `font-family`에 적힌 순서대로 고르는 것과 같은 방식입니다.

| 순서 | 엔진 | 설명 |
| :--- | :--- | :--- |
| 1 | 시스템 설정 엔진 | 추후 개발. 사용자의 목소리 지문을 학습해, 사용자가 직접 읽는 것과 같은 효과를 내는 엔진. 지금은 자리만 두고 항상 건너뜁니다. |
| 2 | Google 엔진 | 이름에 Google이 든 목소리. |
| 3 | Microsoft 엔진 | 이름에 Microsoft가 든 목소리. |
| 4 | 시스템 기본 엔진 | 기기가 기본으로 정해 둔 목소리. |

- 문서의 언어에 맞는 목소리가 하나라도 있으면 그 안에서 위 순서를 적용합니다. 언어가 맞지 않는 앞 순서의 엔진보다 언어가 맞는 뒤 순서의 엔진을 씁니다.
- 사용자가 목록에서 목소리를 직접 고르면 이 순서를 쓰지 않습니다.

#### 슬라이더

연속된 값을 고르는 설정에 씁니다. 자주 쓰는 값에는 자석 지점을 둡니다.

| 항목 | 규칙 |
| :--- | :--- |
| 모양 | 4px 막대(`--line`)에 16px 원형 손잡이(`--fg`). 폭은 최대 360px. 오른쪽에 지금 값을 고정폭 글씨로 적습니다(예: 125%). |
| 자석 지점 | 읽는 속도는 75 · 100 · 125 · 150 · 175 · 200 · 250%. 끌다가 지점의 ±5% 안에 들어오면 그 값에 붙습니다. |
| 점 | 자석 지점마다 막대 위에 8px 점(`--muted`)을 찍습니다. 지금 값이 그 지점이면 점이 글자색(`--fg`)이 됩니다. 점의 자리는 손잡이 중심이 그 값에 올 때의 자리와 맞춥니다. |
| 키보드 | 방향키로 5%씩 움직이고, 이때는 자석이 붙지 않습니다. 붙으면 지점을 빠져나올 수 없기 때문입니다. |
| 저장 | 값이 바뀔 때마다 다른 설정과 함께 기억합니다. |

- 읽는 곳 안의 하이라이트(`<mark>`)는 그동안 면을 빼서 겹치지 않게 합니다.
- 읽는 곳이 화면 밖에 있으면 보이는 자리까지만 스크롤합니다.

### 슬라이드 짚기

스크립트의 어느 문장을 읽을 때 슬라이드의 어디를 짚을지를 스크립트에 메타데이터로 적습니다. 속성으로 적으므로 소리로 읽히지 않습니다.

| 자리 | 적는 것 | 예 |
| :--- | :--- | :--- |
| 슬라이드의 요소 | `data-key="이름"` | `<li data-key="need">` |
| 스크립트의 문단, 또는 문장을 감싼 `<span>`·`<mark>` | `data-cue="이름:방식"`. 여러 개는 빈칸으로 잇습니다. | `<p data-cue="need:box">` |

| 방식 | 모양 | 남는 동안 | 쓰는 곳 |
| :--- | :--- | :--- | :--- |
| `underline` (기본) | 굵은 밑줄 | 그 문장을 읽는 동안 | 짧은 글, 범례의 항목 |
| `box` | 글자색 테두리. 그림의 선과 면은 굵은 선 | 그 문장을 읽는 동안 | 카드, 표·범례 묶음, 그림의 한 부분 |
| `check` | 끝에 체크 표시(✓) | 읽기가 끝나거나 멈출 때까지 | 요약 목록의 줄. 읽어 나가며 하나씩 채워집니다 |

- 문단에 적으면 그 문단의 모든 문장에, 문장을 감싼 요소에 적으면 그 문장에만 걸립니다.
- 이름은 그 슬라이드 안에서만 찾습니다. 다른 슬라이드에 같은 이름이 있어도 섞이지 않습니다.
- 짚는 색은 토큰 `--cue` 하나입니다. 기본은 빨강(`#d32f2f`)이고 설정에서 바꿉니다. 역할 토큰만 쓴다는 색 규칙의 예외이며, 슬라이드 짚기와 자막의 단어 표시에만 씁니다. 스크립트 쪽의 읽는 곳 표시는 그대로 중립 토큰을 씁니다.
- 색만으로 뜻을 전하지 않도록, 짚기는 항상 선이나 표식의 모양과 함께 씁니다.

### 자막

전체 화면에서는 스크립트가 보이지 않으므로, 읽는 문장을 자막으로 보여 줍니다.

| 항목 | 규칙 |
| :--- | :--- |
| 단추 | 단추 줄의 맨 왼쪽, 공통 아이콘의 「자막」(`i-cc`). 처음에 켜져 있고(채운 모양), 누르면 끄고 켭니다. 설정의 「자막」 줄과 같은 값입니다. |
| 보이는 때 | 전체 화면이고 자막이 켜져 있을 때. 읽는 동안에는 읽는 문장을, 읽기를 멈춘 동안에는 멈춘 문장을 계속 보여 줍니다. 한 번도 읽지 않은 슬라이드에는 내지 않습니다. 본문 화면에서는 스크립트가 보이므로 자막을 내지 않습니다. |
| 내용 | 지금 읽는 문장 하나. 문장이 길면 쉼표에서 끊어 지금 읽는 조각만 보여 줍니다. 아래 「긴 문장 끊기」. |
| 읽는 단어 | 「읽는 곳」이 단어이면 읽는 단어 뒤에 짚는 색 상자를 깝니다. 다음 단어가 **같은 줄** 에 있으면 상자가 그 자리로 미끄러지며 폭도 함께 바뀝니다(0.16초). 다음 단어가 **다른 줄** 에 있으면 미끄러지지 않고, 사라졌다가(0.13초) 새 자리에서 나타납니다. 문장이나 조각이 바뀔 때도 사라졌다가 나타납니다. 동작 줄이기를 켠 사용자에게는 바로 옮깁니다. |
| 자리 | 기본은 아래 가운데. 설정에서 위·아래와 왼쪽·가운데·오른쪽을 고릅니다. 가장자리에서 세로 5%, 가로 4% 띄웁니다. |
| 모양 | 기본은 검정 배경에 불투명도 30%, 뒤를 살짝 흐리게(blur 4px), 흰 글자. 배경색·불투명도·흐림 세기는 설정의 「자막 모양」에서 바꾸고, 글자색은 배경이 밝으면 검정, 어두우면 흰색으로 자동으로 고릅니다. 모서리는 중간 단계. 글자는 화면 폭의 2.1%(16px ~ 46px)에 설정의 「글자 크기」(50 ~ 200%)를 곱한 크기이고, 안쪽 여백과 단어 상자도 글자에 맞춰 함께 커집니다. 폭은 화면의 84%를 넘지 않고, 넘치면 아래 「자막의 줄 나누기」대로 줄을 바꿉니다. |
| 테마와의 관계 | 자막은 슬라이드 위에 겹치는 영상 자막이라 테마의 역할 토큰을 따르지 않고 위 설정 값을 씁니다. 짚는 색과 함께 색 규칙의 예외입니다. |
| 겹침 | 슬라이드 위에 겹쳐 놓습니다. 자막은 눌리지 않아 아래의 그림과 단추를 가리지 않고 누를 수 있습니다. |

#### 긴 문장 끊기

자막의 단위는 문장 하나입니다. 다만 문장이 길어 절과 절 사이에 쉼표가 있으면, 그 쉼표에서 끊어 조각 하나씩 보여 줍니다. 자막이 여러 줄로 불어나 슬라이드를 가리는 것을 막기 위해서입니다.

| 항목 | 규칙 |
| :--- | :--- |
| 끊는 문장 | 36자를 넘는 문장만. 그보다 짧으면 쉼표가 있어도 한 번에 보여 줍니다. |
| 끊는 자리 | 쉼표와 그 뒤의 빈칸. 쉼표는 앞 조각의 끝에 남깁니다. |
| 나열의 쉼표 | 끊지 않습니다. 「필요, 행동, 장벽, 착각, 개선」처럼 예시나 항목을 늘어놓는 쉼표는 문장을 가르는 쉼표가 아니기 때문입니다. 쉼표 앞의 토막(앞 쉼표나 문장 처음부터)이 8자 이하이거나, 다음 쉼표까지의 토막이 8자 이하이면 나열로 봅니다. 「예를 들어,」 「첫째,」 같은 짧은 머리말 뒤에서도 같은 규칙으로 끊지 않습니다. |
| 조각의 최소 길이 | 14자. 끊어서 생기는 조각이 이보다 짧으면 끊지 않고 옆 조각에 붙입니다. |
| 조각을 넘기는 때 | 읽는 자리가 다음 조각의 첫 단어에 닿을 때. 「읽는 곳」 설정이 문단이나 문장이어도 조각은 읽는 자리를 따라갑니다. 단어 위치를 알려 주지 않는 목소리는 재어 둔 빠르기로 어림한 자리를 씁니다. |
| 바뀌지 않는 것 | 소리는 문장 하나를 한 번에 읽습니다(조각마다 끊어 읽지 않음). 스크립트의 읽는 곳 표시, 슬라이드 짚기, 진행 막대도 문장 단위 그대로입니다. 끊는 것은 자막에 보이는 글뿐입니다. |

| 문장 | 자막 |
| :--- | :--- |
| 혁신가는 새롭다는 것 자체가 이유이고, 얼리 어답터는 불완전해도 가능성을 보고 먼저 씁니다. | 「혁신가는 새롭다는 것 자체가 이유이고,」 → 「얼리 어답터는 불완전해도 가능성을 보고 먼저 씁니다.」 |
| 각 장은 필요, 행동, 장벽, 착각, 개선의 다섯 칸으로 씁니다. | 끊지 않음 (나열) |
| 첫째, 안 되는 것을 될 때까지 하는 것이 아니라 왜 안 되는지를 파악해야 합니다. | 끊지 않음 (짧은 머리말) |

#### 자막의 줄 나누기

「긴 문장 끊기」가 자막을 **여러 번에 나눠** 보여 주는 규칙이라면, 이 규칙은 한 번에 보여 주는 자막 안에서 **줄을 어디서 바꿀지** 정합니다. 글이 화면 폭에 맞춰 아무 데서나 넘어가면 둘째 줄에 한두 단어만 남거나 단어 중간에서 끊겨 읽기 어렵기 때문입니다.

| 항목 | 규칙 |
| :--- | :--- |
| 직접 정하기 | 스크립트 문장 안의 `<wbr data-cap>` 자리에서 자막의 줄을 바꿉니다. 본문 스크립트에는 아무것도 보이지 않고, 읽는 소리도 바뀌지 않습니다. 표시가 있는 자막은 아래 「고르게 나누기」를 하지 않습니다. |
| 고르게 나누기 | 표시가 없는데 폭이 넘쳐 여러 줄이 되면, 그 줄 수로 고르게 나눕니다. 한 줄로 늘어놓았을 때의 폭을 재서 띄어쓰기 자리 가운데 n 등분 지점에 가장 가까운 곳에서 줄을 바꿉니다. 두 줄이면 대략 가운데입니다. 나눈 줄이 다시 넘치면 한 줄씩 늘려 다시 나누고, 4줄까지 시도합니다. |
| 다시 나누는 때 | 자막 조각이 바뀔 때, 창 크기가 바뀔 때, 설정의 「글자 크기」나 가로 자리를 바꿀 때. |
| 글자 | 줄을 바꿔도 글자는 하나도 빼거나 더하지 않습니다(줄 사이에 줄바꿈만 넣음). 그래서 읽는 단어 상자는 줄이 바뀐 자막에서도 제 단어를 따라갑니다. |
| 띄어쓰기가 없는 글 | 고르게 나눌 띄어쓰기 자리가 없으면 화면 폭에 맞춰 넘어가는 대로 둡니다. |

```html
<span class="sent">이 문장은 여기서 <wbr data-cap>자막의 줄을 바꿉니다.</span>
```

읽는 동안 화면 맨 아래에 진행 막대를 보여 줍니다.

| 항목 | 규칙 |
| :--- | :--- |
| 모양 | 화면 맨 아래에 붙은 1px 선, 짚는 색(`--cue`, 기본 빨강). 바탕 줄은 그리지 않고 지나온 만큼만 그립니다. 마우스를 올리면 3px로 굵어집니다. |
| 보이는 때 | 한 번이라도 재생한 뒤로는 계속 보입니다. 멈춰도, 끝까지 읽어도 지우지 않습니다. 전체 화면에서도 같은 자리에 보입니다. 다른 탭으로 가면 감추고, 돌아오면 다시 보입니다. |
| 자리 기억 | 어디까지 읽었는지를 슬라이드마다(다음에 읽을 문장), 탭마다(이어 재생이 머문 슬라이드) 기억합니다. 멈춘 막대는 그 자리를 가리킵니다. 페이지를 새로 열면 기억은 사라집니다. |
| 다시 재생 | 스피커 단추나 재생 단추를 다시 누르면 기억해 둔 자리의 문장부터 읽습니다. 끝까지 읽은 슬라이드는 처음부터, 이어 재생에서 끝까지 읽은 슬라이드는 다음 슬라이드부터, 마지막 슬라이드까지 다 읽었으면 탭의 처음부터 읽습니다. |
| 기준 | 다 읽은 문장 수 ÷ 전체 문장 수. 슬라이드 하나를 읽을 때는 그 슬라이드의 문장, 이어 재생일 때는 탭 전체의 문장이 전체입니다. |
| 움직임 | 문장을 읽기 시작하면 그 문장의 끝 자리까지, 재어 둔 빠르기로 어림한 시간 동안 고른 빠르기로 나아갑니다. 다음 문장이 시작될 때 다 읽은 자리에 정확히 다시 맞춥니다. |
| 눌러서 옮기기 | 막대의 한 자리를 누르면 그 자리에 해당하는 문장부터 읽습니다. 이어 재생 중이면 다른 슬라이드로도 옮겨 갑니다. 멈춰 있을 때 눌러도 마지막에 재생하던 것(슬라이드 하나 또는 탭 전체)을 그 자리부터 다시 읽습니다. |
| 너그러운 누르기 | 누르는 자리는 화면 아래 18px 높이의 띠 전체입니다. 선이 1px이라 정확히 맞히지 않아도 되게 합니다. |

### 이어 재생

탭이 슬라이드로 쓰여 있으면 헤더에 재생 단추를 둡니다. 한 번 누르면 그 탭의 슬라이드를 처음부터 끝까지 차례로 읽습니다.

| 항목 | 규칙 |
| :--- | :--- |
| 단추 | 헤더 오른쪽 묶음의 맨 앞(필터의 왼쪽). 공통 아이콘의 「재생」(`i-play`). 재생 중에는 「정지」(`i-stop`)에 채운 모양이 되고, 누르면 멈춥니다. |
| 보이는 때 | 지금 탭에 슬라이드가 있을 때만. 슬라이드가 없는 탭과 읽어 주기 기능이 없는 브라우저에서는 숨깁니다. |
| 순서 | 처음에는 그 탭의 첫 슬라이드부터, 재생한 적이 있으면 기억해 둔 자리부터(위 「진행 막대」의 다시 재생). 슬라이드 하나의 스크립트를 끝까지 읽으면 다음 슬라이드가 화면 위쪽에 오도록 부드럽게 스크롤하고, 스크롤이 끝나면 그 슬라이드를 읽습니다. 다음 슬라이드를 읽기 전에 적어도 0.6초는 쉽니다. 스크롤이 끝난 것은 `scrollIntoView()`가 돌려주는 Promise로 알고, 그것이 없는 브라우저에서는 스크롤 영역의 `scrollend` 이벤트로, 그마저 없거나 스크롤이 일어나지 않으면 스크롤 이벤트가 0.1초 동안 없을 때로 봅니다. 위치를 몇 차례 재서 짐작하지 않습니다. 끝 슬라이드를 다 읽으면 멈춥니다. |
| 재생 중의 화면 | 읽는 슬라이드를 화면에 둡니다. 스크립트의 읽는 곳을 따라 스크롤하지 않습니다. |
| 전체 화면에서 | 스크롤 대신 다음 슬라이드로 넘깁니다. |
| 멈추는 때 | 단추를 다시 누를 때, Esc, 슬라이드의 스피커 단추를 누를 때, 전체 화면에서 직접 슬라이드를 넘길 때, 탭을 바꿀 때. |

## 슬라이드 색

슬라이드 안의 그림에 색을 입힙니다. 색은 UniPalette로 고른 **5×3 팔레트**(색조 5개 × 명암 3단계)에서만 가져옵니다. 문서마다 색 값을 따로 적지 않으므로, 보는 사람이 설정에서 한 번 바꾸면 모든 슬라이드에 함께 적용됩니다.

| 항목 | 규칙 |
| :--- | :--- |
| 팔레트 | 색조 5개 × 명암 3단계(어둡게 · 가운데 · 밝게). 기본값은 UniPalette의 기본값(기준색 `#E44D1B`, 선형 추출, 명암 20 ~ 80)으로 뽑은 5×3입니다. |
| 토큰 | 값은 `:root`의 `--sp1-d` ~ `--sp5-l`(색조 1~5 × d · m · l)에 둡니다. 그림은 값이 아니라 역할 이름만 씁니다: `--spN-fill`(면) · `--spN-ink`(선 · 글자) · `--spN-mid`(가운데 톤: 화살표 · 테두리 · 표시). |
| 테마 | 밝은 테마는 밝은 톤을 면, 어두운 톤을 선 · 글자로 씁니다. 어두운 테마(`data-skin`이 dark · navy)는 둘을 바꿉니다. 가운데 톤은 그대로 둡니다. |
| 색조의 뜻 | 색조 번호에 뜻을 고정하지 않습니다. 문서가 자기 그림에서 역할을 정하고(예: 1 강조 · 2 정식 경로 · 4 흐름 · 5 하지 않는 것), 같은 문서 안에서는 같은 뜻을 지킵니다. 색만으로 뜻을 전하지 않고 모양(실선 · 점선 · 굵기)이나 글자와 함께 씁니다. |
| 공통 부분 | 슬라이드 번호 배지(`.slide-no`)는 색조 1의 글자색 면에 면색 글자, 요약 목록의 표시(`::marker`)는 색조 1의 가운데 톤. |
| 짚는 색과의 관계 | 슬라이드 짚기의 색(`--sl-cue`)은 팔레트와 따로 둡니다. 읽는 곳을 가리키는 색이 그림 색과 섞이지 않게 하기 위해서입니다. |
| 설정 줄 | 읽기 설정의 「슬라이드 색」 줄: 5칸 미리보기(칸마다 명암 3단계를 위에서 아래로) · 「고르기」 · 「기본값」. 저장한 값이 없으면 「기본값」이 눌린 모양입니다. |
| 고르기 | UniPalette 간단 보기를 개수 5 · 명암 3단계로 띄웁니다(제목 「슬라이드 색 고르기」). 고르는 동안 슬라이드에 바로 적용하고, 「선택」이면 저장, 「취소」이면 고르기 전의 색으로 되돌립니다. 대화상자의 밝기는 지금 테마를 따릅니다. |
| 불러오기 | UniPalette는 「고르기」를 누를 때만 불러옵니다(전체 설정의 UniPalette 테마와 같은 주소). 평소에는 저장한 값만 읽어 적용합니다. |
| 기억 | `iseohyun_slides_palette_v1`에 `[[어둡게, 가운데, 밝게] × 5]`를 저장합니다. 읽기 · 쓰기에 실패하거나 모양이 어긋나면 기본값으로 동작하고 경고만 남깁니다. 「기본값」은 저장한 값을 지웁니다. |
| 사이트 배색과의 관계 | 전체 설정의 UniPalette 테마와는 따로입니다. 사이트 배색은 화면의 뼈대를, 슬라이드 색은 슬라이드 안의 그림을 칠합니다. |
| 구현 | 지금은 `modules/features/slides-palette.css` · `slides-palette.js`가 따로 맡고, 슬라이드 문서의 머리에서 `slides.css` · `slides.js` 다음에 함께 불러옵니다. 읽기 설정 상자에 줄을 덧붙이는 방식이므로, `slides.js`의 정리가 끝나면 그쪽에 합칩니다. 읽어 주기 기능이 없는 브라우저는 읽기 설정 자체가 없어 이 줄도 나타나지 않습니다. |

## 항목 카드

스크립트 밖에 짧은 글을 카드로 둡니다. 내가 겪고 생각한 것과 Claude의 의견을 모양으로 구분합니다.

| 항목 | 규칙 |
| :--- | :--- |
| 내 경험과 생각 | `<div class="note">`. 실선 테두리의 카드. |
| Claude의 의견 | `<div class="note claude">`. 점선 테두리, 바탕 없음. |
| 안의 구성 | 맨 위에 종류 라벨(`.kind`, 예: 「막힌 벽」 「Claude의 의견」), 제목(`h2`), 본문 문단, 맨 아래에 날짜와 출처(`.meta`). |
| 제목 | 목차에 오르도록 `h2`로 씁니다. 카드 안에서는 번호와 밑줄을 그리지 않습니다. 다만 사이트의 제목 번호는 카드의 `h2`도 세므로, 슬라이드 묶음 사이에 카드를 끼우면 뒤 슬라이드의 번호가 밀립니다. 슬라이드가 있는 장에서는 카드를 슬라이드 묶음 뒤에 모읍니다. |
| 글쓴이 필터 | 카드가 있는 문서는 헤더의 필터 패널에 「글쓴이」 줄을 둡니다: 전체(기본) · 내 경험과 생각 · Claude의 의견. 고른 쪽의 카드만 보이고, 전체가 아니면 필터 아이콘에 점을 찍습니다. |

## 좁은 화면

슬라이드가 놓인 자리의 폭이 560px 아래로 내려가면 16:9를 풉니다. 글자를 읽을 수 없을 만큼 줄이는 대신, 같은 내용을 세로로 쌓고 글자는 13px로 고정합니다. 그림이 위, 범례가 그 아래에 옵니다.

## 그 밖의 연결

| 항목 | 규칙 |
| :--- | :--- |
| 목차 | 사이드바 패널의 목차에는 묶음 제목이 나옵니다. |
| 주소 | 묶음마다 `#이름`을 붙여, 주소로 그 슬라이드 자리에 바로 갈 수 있게 합니다. |
| 그림 크게 보기 | 슬라이드 안의 작은 그림은 누르면 그 슬라이드 안에서 크게 엽니다. 규칙은 [「그림 보기」 규칙](#/column/ai/webapp-common-gui/rules/image-viewer.md). |
| 인쇄 | 전체 화면 단추와 쪽 번호는 인쇄하지 않고, 슬라이드와 스크립트가 쪽 사이에서 갈라지지 않게 합니다. |
