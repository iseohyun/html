# 설치

웹앱을 브라우저의 「설치」로 홈 화면에 올릴 수 있게 합니다. 필요한 것은 웹 앱 매니페스트 파일 하나와 아이콘 몇 장이고, 서버나 앱 장터는 쓰지 않습니다.

- 매니페스트가 없으면 브라우저는 그 사이트를 앱으로 보지 않습니다. 「설치」는 막히고 「바로가기 만들기」만 됩니다.
- 설치와 오프라인은 다른 일입니다. 설치는 매니페스트만으로 되고, 오프라인 실행은 서비스 워커가 따로 있어야 합니다.

## 설치와 바로가기의 차이

| 항목 | 바로가기 | 설치 |
| :--- | :--- | :--- |
| 여는 모습 | 브라우저 탭. 주소창과 탭이 보임 | 주소창 없는 독립 창 |
| 기기에서의 취급 | 홈 화면의 아이콘일 뿐 | 앱 목록과 최근 앱에 따로 나옴 |
| 아이콘 | 브라우저 표식이 붙음 | 앱 아이콘 그대로 |
| 시작 화면 | 없음 | 아이콘과 배경색으로 자동 생성 |
| 아이폰의 푸시 알림 | 받지 못함 | 받음 |

## 설치가 되는 조건

| 조건 | 내용 |
| :--- | :--- |
| 매니페스트 연결 | `index.html`의 `<head>`에 `<link rel="manifest">`가 있습니다. |
| 이름 | 매니페스트에 `name` 또는 `short_name`이 있습니다. |
| 아이콘 | 192px과 512px PNG가 한 장씩 있습니다. |
| 시작 주소 | `start_url`이 있습니다. |
| 표시 방식 | `display`가 `standalone`입니다. |
| 보안 연결 | HTTPS로 서비스합니다. 개발할 때의 `localhost`는 예외로 통과합니다. |

서비스 워커는 조건이 아닙니다. 예전의 Chrome은 요구했지만 지금은 매니페스트만으로 설치됩니다.

## 매니페스트

파일 이름은 `manifest.webmanifest`이고 `index.html`과 같은 자리에 둡니다.

```json
{
  "name": "앱의 전체 이름",
  "short_name": "짧은 이름",
  "description": "한 줄 설명",
  "lang": "ko",
  "start_url": "./",
  "scope": "./",
  "display": "standalone",
  "background_color": "#ffffff",
  "theme_color": "#ffffff",
  "icons": [
    { "src": "./icon-192.png", "sizes": "192x192", "type": "image/png", "purpose": "any" },
    { "src": "./icon-512.png", "sizes": "512x512", "type": "image/png", "purpose": "any" },
    { "src": "./icon-maskable-512.png", "sizes": "512x512", "type": "image/png", "purpose": "maskable" }
  ]
}
```

| 항목 | 규칙 |
| :--- | :--- |
| `name` | 설치 창과 시작 화면에 나오는 전체 이름. 문서의 `<title>`과 맞춥니다. |
| `short_name` | 홈 화면 아이콘 아래에 나오는 이름. 12자 안쪽으로 잡아 잘리지 않게 합니다. |
| `start_url`, `scope` | 둘 다 `./`. 도메인과 하위 폴더를 적지 않습니다. |
| `display` | `standalone`. 주소창을 숨기되 기기의 상태 표시줄은 남깁니다. |
| `background_color` | 시작 화면의 배경. 앱의 본문 배경색과 같게 합니다. |
| `theme_color` | 상태 표시줄과 창 머리의 색. `<head>`의 `theme-color`와 같은 값입니다. |
| `orientation` | 적지 않습니다. 세로로만 쓰는 앱일 때만 `portrait`를 적습니다. |

`<head>`에는 아래 줄을 넣습니다.

```html
<link rel="manifest" href="./manifest.webmanifest">
<meta name="theme-color" content="#ffffff">
<link rel="apple-touch-icon" href="./icon-512.png">
```

## 아이콘

| 파일 | 크기 | 쓰이는 곳 | 그리는 방법 |
| :--- | :--- | :--- | :--- |
| `icon-192.png` | 192px | 홈 화면 | 파비콘과 같은 그림. 모서리 바깥은 투명 |
| `icon-512.png` | 512px | 시작 화면, 설치 창, 아이폰 홈 화면 | 위와 같음 |
| `icon-maskable-512.png` | 512px | 안드로이드가 원이나 둥근 사각형으로 잘라 쓰는 아이콘 | 배경을 네 모서리까지 채우고, 그림은 가운데 80% 원 안에 둠 |

- 원본은 `favicon.svg` 한 장입니다. PNG는 거기서 뽑아내고 손으로 따로 그리지 않습니다.
- 잘라 쓰는 아이콘이 없으면 안드로이드는 보통 아이콘을 줄여 흰 원 안에 넣습니다. 그림이 작아 보이므로 한 장 따로 만듭니다.
- 한 장에 `any maskable`을 함께 적지 않습니다. 잘리지 않으려고 넣은 여백이 보통 아이콘에서는 그림을 작게 만듭니다.

## 한 도메인에 앱이 여럿일 때

같은 도메인의 하위 폴더마다 앱을 두는 배포에서는 `scope`가 앱을 가릅니다.

- `start_url`과 `scope`를 `./`로 쓰면 매니페스트가 놓인 폴더가 앱의 범위가 됩니다. 폴더가 다르면 따로 설치되는 다른 앱입니다.
- 범위 밖의 주소로 넘어가면 독립 창 위쪽에 주소 띠가 나타납니다. 앱 안의 화면은 모두 범위 안의 주소에 둡니다.
- 서비스 워커를 쓰는 앱은 워커의 범위도 같은 폴더로 맞춥니다.
- 저장 키의 접두어는 앱마다 다르게 둡니다. 설치해도 저장 공간은 도메인 단위로 함께 쓰기 때문입니다.

## 오프라인과 서비스 워커

설치만으로는 오프라인에서 열리지 않습니다. 네트워크가 없으면 독립 창에 브라우저의 연결 오류 화면이 나옵니다.

- 오프라인 지원은 기본에 넣지 않습니다. 넣을 때의 규칙은 [「구조」 규칙](#/column/ai/webapp-common-gui/rules/architecture.md)의 「폴더와 빌드」에 있습니다.
- 푸시 알림만 받는 서비스 워커는 파일을 캐시하지 않으므로 오프라인과 상관없습니다. 알림 규칙은 [「푸시 알림」 규칙](#/column/ai/webapp-common-gui/rules/push.md)에 있습니다.

## 아이폰

| 항목 | 내용 |
| :--- | :--- |
| 설치하는 길 | Safari의 공유 → 「홈 화면에 추가」. 설치 단추나 안내 창은 뜨지 않습니다. |
| 아이콘 | 매니페스트의 아이콘보다 `apple-touch-icon`을 먼저 씁니다. 투명한 곳은 검게 칠해지므로 배경이 찬 그림을 씁니다. |
| 독립 창 | 매니페스트의 `display`가 `standalone`이어야 주소창 없이 열립니다. |
| 푸시 알림 | 홈 화면에 추가한 앱에서만 알림 권한을 물을 수 있습니다. |

## 확인과 배포

| 때 | 할 일 |
| :--- | :--- |
| 커밋하기 전 | Chrome 개발자 도구의 Application → Manifest에서 오류와 경고가 없는지 봅니다. 배포할 때와 같은 하위 폴더 주소로 열어서 확인합니다. |
| 빌드 확인 | 매니페스트와 아이콘 파일이 빠지지 않았는지를 빌드 확인 스크립트의 필수 파일 목록에 넣습니다. |
| 배포한 뒤 | 휴대폰의 브라우저 메뉴에서 「설치」가 눌리는지 봅니다. |
| 이미 바로가기를 만든 사용자 | 바로가기는 저절로 앱으로 바뀌지 않습니다. 지우고 다시 설치해야 합니다. |
| 새 판을 배포한 뒤 | 설치한 앱은 닫았다 열어도 메모리의 화면을 이어 쓰고 새로 고침 버튼도 없습니다. [「화면」 규칙](#/column/ai/webapp-common-gui/rules/screen.md)의 「새 판 알림」을 넣어 두어야 사용자가 새 판을 받습니다. GitHub Pages는 파일을 10분 동안 캐시하게 하므로, 확인 요청은 캐시를 쓰지 않습니다. |
| 이름이나 아이콘을 바꿀 때 | 설치된 앱에는 며칠 뒤에 반영되거나 다시 설치해야 반영됩니다. 자주 바꾸지 않습니다. |

> 참조: CharQuiz와 NameQuiz는 매니페스트가 없어 휴대폰에서 「설치」가 막혀 있었고, 매니페스트와 아이콘을 넣어 풀었습니다. 두 앱은 같은 도메인의 서로 다른 하위 폴더에 있습니다.

## 아직 확정하지 않은 값

아래는 처음 적용하면서 임시로 정한 것입니다. 써 보고 사용자가 확정합니다.

| 항목 | 임시 결정 |
| :--- | :--- |
| 기본에 넣을지 | 넣음. 매니페스트와 아이콘은 모든 웹앱에 넣고, 오프라인만 선택으로 남김 |
| 앱 안의 설치 단추 | 두지 않음. 브라우저 메뉴의 「설치」에 맡김 |
| 화면 방향 | 고정하지 않음. 세로로만 쓰는 앱만 `portrait` |
| `theme_color` | 앱의 대표색. 테마를 바꿔도 따라 바꾸지 않음 |
| 아이폰용 아이콘 | 따로 만들지 않고 `icon-512.png`를 같이 씀 |
