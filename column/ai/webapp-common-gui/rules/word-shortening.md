# 단어 단축

달력 칩이나 표처럼 좁은 칸에서 긴 이름을 줄여 보여 주는 기능입니다. KoreaEvent의 「축약보기」에서 구조를 가져왔습니다. 자료는 그대로 두고 화면에 그릴 때만 바꿉니다.

## 구성

```text
AbbreviationSettings
├─ enabled                전체 켜기 / 끄기
├─ regexRules[]           정규식 규칙, 목록 순서대로 적용
│  └─ id · label · example · pattern · replacement · enabled
└─ wordRules[]            단어 사전
   └─ id · from · to · count · enabled

applyAbbreviation(text, settings)
  1. 꺼져 있으면 원래 글자를 그대로 돌려줌
  2. 켜진 정규식 규칙을 목록 순서대로 적용
  3. 켜진 단어 규칙을 긴 단어부터 적용
  4. 연속된 공백을 하나로 줄이고 앞뒤 공백 제거
```

| 부분 | 규칙 |
| :--- | :--- |
| 적용 범위 | 화면에 그릴 때만 바꿉니다. 저장된 자료, 검색, 정렬은 원래 이름을 씁니다. |
| 원래 이름 보기 | 줄인 이름에 마우스를 올리면 원래 이름을 보여 주고, 상세 창에는 항상 원래 이름을 씁니다. |
| 정규식 규칙 | 「연도의 년 제거」, 「제N회를 N'로」, 「괄호 안 부가 문구 삭제」처럼 모양으로 잡는 규칙. 규칙마다 이름과 예시를 함께 적어 무엇을 하는지 알 수 있게 합니다. |
| 단어 사전 | 「서울특별시 → 서울」처럼 낱말을 바꾸는 규칙. 긴 단어부터 적용해서 「부산광역시장배」가 「부산광역시」 규칙에 먼저 잘리지 않게 합니다. |
| 잘못된 정규식 | 그 규칙만 건너뛰고 경고를 남깁니다. 화면이 멈추지 않게 합니다. |
| 기본 사전 | 프로젝트에 JSON 파일로 둡니다. KoreaEvent는 전체 자료에서 네 글자 이상 후보를 뽑는 스크립트로 이 파일을 만들고, 단어마다 나온 횟수를 함께 적습니다. |
| 사용자 변경 기억 | 브라우저에 저장합니다. 저장 키 끝에 판 번호를 붙이고, 읽을 때 모양을 확인해서 깨져 있으면 기본 사전으로 돌아갑니다. |

### 설정 화면

| 묶음 | 내용 |
| :--- | :--- |
| 켜기와 미리보기 | 전체 켜기/끄기, 켜진 규칙 수, 글자를 넣으면 줄인 결과를 바로 보여 주는 입력 칸. |
| 정규식 규칙 | 규칙마다 체크, 이름, 예시. 「N / 전체 적용 중」을 머리에 표시. |
| 단어 사전 | 단어마다 체크, 원래 단어, 줄인 단어, 나온 횟수. 줄인 단어는 고쳐 쓸 수 있음. |
| 들어가는 길 | 헤더 설정의 「단어 단축」에서 켜고 끄고, 규칙 편집은 별도 화면에서. |

## 사용자가 고치는 범위

| 대상 | 할 수 있는 일 | 규칙 |
| :--- | :--- | :--- |
| 전체 | 켜기 / 끄기 | 헤더의 설정과 이 화면 어디서 바꿔도 같은 값. |
| 정규식 규칙 | 규칙마다 켜기 / 끄기 | 패턴은 보여 주기만 하고 고칠 수 없습니다. 잘못된 정규식이 화면을 망가뜨리는 일을 막기 위해서입니다. |
| 단어 사전 | 켜기 / 끄기, 줄인 단어 고치기, 단어 추가, 삭제 | 줄인 단어 칸에서 벗어나면 바로 적용. 사용자가 추가한 단어에는 「추가함」 표시. |
| 단어 추가 확인 |  | 원래 단어는 두 글자 이상, 줄인 단어는 원래 단어보다 짧게, 이미 있는 단어는 받지 않고 이유를 알려 줍니다. |
| 기억 |  | 정규식은 켜짐 여부만, 단어는 목록 전체를 브라우저에 저장합니다. |

## 확정한 값

| 항목 | 결정 |
| :--- | :--- |
| 처음 상태 | 켜 둠 |
| 적용할 자리 | 달력과 리스트 모두 |
| 사용자 편집 | 켜고 끄기 + 단어 추가·수정 |
| 기본 규칙 | 비워 둠. 기본 화면은 기능과 화면만 제공하고, 규칙은 프로젝트가 자기 자료에 맞게 채웁니다. |

> 기본 화면의 규칙은 비어 있지만, 비어 있으면 견본에서 보여 줄 것이 없어 이 페이지에는 예시 규칙 9개를 넣어 두었습니다. 프로젝트가 채워 넣은 모습으로 보시면 됩니다. 규칙이 하나도 없으면 설정의 단어 단축 항목과 이 화면은 「규칙이 없습니다」 안내만 보여 줍니다.
