# 필터

필터는 헤더 한 곳에만 있습니다. 헤더 오른쪽의 깔때기 아이콘을 누르면 헤더 아래로 펼쳐지고, 달력과 리스트가 같은 값을 따릅니다.

## 구성

```text
HeaderBar
├─ 필터 아이콘            펼침 여부와 적용 여부를 보여 줌
└─ FilterPanel            헤더 아래에 붙어 펼쳐짐
   └─ TopicRow            한 줄에 주제 하나
      ├─ TopicLabel       왼쪽, 주제 이름
      └─ ControlsLine     오른쪽, 컨트롤을 가로로 나열
         ├─ 하나 고르기 버튼
         ├─ 여러 개 고르기 버튼 (체크 표시 · 건수)
         ├─ 선택 상자
         ├─ 검색 입력 (돋보기 · 지우기)
         └─ 초기화 버튼   마지막 줄 오른쪽 끝
```

| 부분 | 내용 | 동작 |
| :--- | :--- | :--- |
| 필터 아이콘 | 헤더 오른쪽 시스템 아이콘. | 누르면 패널을 여닫음. 열려 있으면 채운 모양. 값이 하나라도 걸려 있으면 오른쪽 위에 점. |
| 패널 | 헤더 안, 탭 줄 바로 아래. 본문과 같은 최대 폭. | 높이와 투명도를 함께 바꿔 펼침. 헤더와 함께 고정되어 스크롤해도 남음. |
| 주제 줄 | 왼쪽 76px에 주제 이름, 오른쪽에 컨트롤. | 컨트롤이 많으면 오른쪽 안에서 줄바꿈. 줄 사이는 점선. |
| 하나 고르기 | 「전체」로 시작하는 버튼 묶음. | 하나만 켜짐. |
| 여러 개 고르기 | 체크 표시, 이름, 건수. | 각각 켜고 끔. 아무것도 안 켜면 전체. |
| 날짜 | 빠른 버튼 네 개와 그 옆의 시작일 ~ 종료일 입력 칸. | 빠른 버튼을 누르면 계산된 범위가 입력 칸에 채워짐. 입력 칸을 직접 고치면 빠른 버튼이 모두 꺼짐. 한쪽만 넣으면 그날부터 또는 그날까지. 범위와 하루라도 겹치는 항목을 남김. |
| 검색 입력 | 왼쪽 돋보기, 오른쪽 지우기 버튼. | 글자를 넣는 즉시 적용. 지우기 버튼은 글자가 있을 때만 보임. 단어 단축이 켜져 있어도 줄이기 전 이름으로 찾음. |
| 초기화 | 마지막 줄 오른쪽 끝. | 모든 값을 처음으로 되돌림. |

### 원칙

- 필터 컨트롤을 본문 여기저기에 흩지 않습니다. 지역, 날짜, 분류, 상태, 검색을 모두 이 패널 한 곳에서 다룹니다.
- 필터는 **무엇을 보여 줄지**, 설정은 **어떻게 보여 줄지** 를 맡습니다. 둘을 섞지 않습니다.
- 필터 값은 페이지를 바꿔도 유지합니다. 달력에서 건 필터가 리스트에도 그대로 걸립니다.
- 결과가 0건이면 본문의 빈 상태에서 필터를 풀라고 안내합니다.

## 스타일

| 부분 | 치수 | 모양 |
| :--- | :--- | :--- |
| 패널 | 안쪽 12px 16px, 줄 사이 10px | 본문 바탕 색, 아래에 1px 선. 활성 탭과 같은 색이라 탭에서 이어져 보임. |
| 펼침 전환 | 0.3초 | `grid-template-rows: 0fr → 1fr`와 투명도. |
| 주제 줄 | 76px + 나머지, 사이 12px | 아래에 1px 점선, 마지막 줄은 없음. |
| 주제 이름 |  | 0.8rem 굵게. |
| 고르기 버튼 | 높이 30px, 안쪽 0 11px | `--r-md`, 1px 테두리, 0.78rem. 켜지면 글자색으로 채운 면. |
| 체크 표시 | 14px | `--r-sm` 네모, 켜지면 안에 체크. |
| 건수 | 최소 폭 18px | 알약형, 0.68rem. |
| 검색 입력 | 높이 32px, 최대 폭 400px | `--r-md`, 1px 테두리, 좌우 30px를 아이콘 자리로 비움. |
| 날짜 입력 | 높이 30px | `--r-md`, 1px 테두리, 0.78rem. 두 칸 사이에 「~」. |
| 적용 표시 점 | 8px | 필터 아이콘 오른쪽 위, `--alert` 빨강 원에 표면 색 테두리. |

## 주소에 담기

지금 걸린 필터를 주소에 함께 적습니다. 공유 버튼으로 복사한 링크를 연 사람은 같은 페이지를 같은 필터로 보고, 새로 고쳐도 필터가 남습니다.

- 필터를 바꿀 때마다 주소를 고쳐 씁니다. 기본값인 항목은 적지 않아 주소를 짧게 유지합니다.
- 주소를 읽을 때는 항목마다 아는 값인지 확인하고, 모르는 값은 버리고 기본값을 씁니다.
- 설정(테마, 언어, 보기 방식)은 주소에 담지 않습니다. 받는 사람의 설정을 바꾸지 않기 위해서입니다.
- 실제 프로젝트에서는 `?cat=전시&region=서울,제주&date=month`처럼 읽기 쉬운 이름으로 적습니다.

> 이 견본은 미리보기 환경이 글자·숫자·하이픈으로 된 `#이름`만 전달하기 때문에 `#list-c3-r04-dm` 같은 짧은 부호로 적습니다. 순서대로 페이지, 분류, 지역, 상태, 날짜, 검색어입니다.

## 확정한 값

| 항목 | 결정 |
| :--- | :--- |
| 적용 표시 점 | 빨강 (`--alert`). 스톤 테마에서만 글자색. |
| 초기화 버튼의 호버 | 다른 버튼과 같게 |
| 필터 값을 주소에 | 담는다 |
| 좁은 화면의 패널 | 넓은 화면과 같이 헤더 아래로 펼침 |
| 날짜 주제 | 빠른 버튼(전체, 이번 주, 이번 달, 다음 달) + 시작일·종료일 직접 고르기 |
