# 리스트

같은 자료를 표와 카드 두 가지로 보여 줍니다. KoreaEvent의 표 보기와 카드 보기, KoreaIssue의 자료 표에서 구조를 가져왔습니다.

## 구성

```text
ListView
├─ SummaryRow             왼쪽에 건수, 오른쪽에 안내
├─ TableView
│  └─ TableCard           가로로 넘치면 카드 안에서만 스크롤
│     ├─ thead            정렬 가능한 열 머리 (설정에서 고른 열만)
│     └─ tbody > Row      지역 · 분류 · 이름 · 기간 · 상태
├─ CardGrid
│  └─ Card
│     ├─ Thumb            (선택) 그림과 그 위의 배지
│     ├─ CardBody         태그 줄 · 제목 · 정보 줄
│     └─ CardFooter       출처 · 「자세히」
├─ MoreButton             남은 항목이 있을 때만
└─ EmptyState             결과가 없을 때
```

| 부분 | 내용 | 동작 |
| :--- | :--- | :--- |
| 요약 줄 | 「총 12건」처럼 건수를 굵게. 필터가 걸려 있으면 그 사실을 옆에 적음. | 폭이 모자라면 줄바꿈. |
| 보기 전환 | 표 / 카드. 기본은 표. | 헤더의 설정에서 바꿈. 본문에는 전환 버튼을 두지 않음. |
| 표시 열 | 보일 열을 고름. 이름 열은 항상 보임. | 헤더의 설정에서 바꿈. 표로 볼 때만 나오는 항목. 숨긴 열로 정렬 중이었다면 기본 정렬로 돌아감. |
| 정렬 | 오래된순 / 최신순. | 헤더의 설정에서 바꿈. 기간 열을 기준으로 하고 달력과 같은 값을 씀. 그 뒤에 열 머리를 눌러 다른 열로 정렬할 수 있음. |
| 열 머리 | 열 이름과 위아래 화살표 아이콘. | 누르면 오름차순, 다시 누르면 내림차순. 정렬 중인 열은 화살표가 한 방향으로 바뀜. |
| 행 | 짧은 값은 태그나 배지로, 이름은 굵게, 날짜는 흐리게 한 줄로. | 호버하면 바탕이 바뀌고, 누르면 상세 창을 엶. 견본에는 상세 창이 없습니다. |
| 카드 | 위에서부터 태그 줄, 제목, 정보 줄, 바닥 줄. 정보 줄은 카드 아래쪽에 붙임. | 호버하면 3px 떠오르고 테두리가 진해짐. |
| 더 보기 | 목록 아래 가운데 버튼. 남은 건수를 함께 적음. | 처음에 정해진 수만 그리고, 누를 때마다 같은 수만큼 더 그림. 필터를 바꾸면 처음 수로 돌아감. 남은 것이 없으면 버튼을 숨김. |
| 빈 상태 | 무엇이 없는지와 어떻게 하면 나오는지를 한두 줄로. | 없음 |

한 번에 그리는 수는 표 50건, 카드 24건입니다. 견본은 예시가 12건뿐이라 6건씩 그립니다.

## 스타일

| 부분 | 치수 | 모양 |
| :--- | :--- | :--- |
| 요약 줄 | 아래 간격 14px | 건수 0.9rem 굵게, 안내 0.8rem 흐리게. |
| 표 카드 |  | 표면 색, 1px 테두리, `--r-lg`. |
| 열 머리 | 안쪽 9px 12px | 가라앉은 면, 0.78rem 굵게, 줄바꿈 없음. 화살표 14px. |
| 칸 | 안쪽 11px 12px | 0.86rem, 세로 가운데, 아래에 1px 선. 마지막 행은 선 없음. |
| 이름 칸 | 최소 폭 180px | 굵게. |
| 태그 | 안쪽 1px 7px | `--r-sm`, 가라앉은 면에 흐린 글자, 0.72rem. |
| 상태 배지 | 안쪽 1px 9px | `--r-pill`. 진행중은 채운 면, 예정은 테두리만, 종료는 흐린 면. 색 대신 채움으로 구분. |
| 카드 격자 | 최소 300px, 사이 16px | 폭에 맞춰 열 수가 자동으로 바뀜. |
| 카드 | 안쪽 14px 16px | 표면 색, 1px 테두리, `--r-lg`. 제목 0.96rem 굵게. |
| 카드 바닥 줄 | 안쪽 9px 16px | 바탕 색, 위에 1px 선, 0.75rem 흐리게. |
| 카드 그림 | 높이 158px | 쓸 때만. 그림이 없으면 영역 자체를 뺌. |
| 더 보기 버튼 | 높이 32px, 위 간격 14px | 다른 글자 버튼과 같은 모양, 가운데 정렬. |
| 빈 상태 | 안쪽 44px 24px | 점선 테두리, 가운데 정렬, 흐린 글자. |

## 확정한 값

| 항목 | 결정 |
| :--- | :--- |
| 보기 전환의 자리 | 헤더 시스템 아이콘의 설정 안 |
| 표시 열 고르기 | 설정 안에서 고름 |
| 기본 보기 | 표 |
| 많은 항목 처리 | 더 보기 버튼 |
| 정렬 | 오래된순이 기본, 최신순으로 거꾸로 볼 수 있음. 달력과 함께 바뀜 |
| 한 번에 그리는 수 | 표 50건, 카드 24건. 24는 2·3·4열 어디서나 줄이 맞는 수입니다. |
