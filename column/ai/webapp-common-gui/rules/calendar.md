# 달력

KoreaEvent의 달력 보기에서 구조를 가져왔습니다. 한 해 열두 달을 카드로 쌓고, 위에 붙은 막대로 달을 오갑니다.

## 구성

```text
CalendarView
├─ MonthNavBar            위에 붙어 따라옴
│  ├─ 달 이동 버튼        1월 ~ 12월, 누르면 그 달 카드로 이동
│  └─ 오른쪽 컨트롤       「오늘」 버튼
└─ YearStack              달 카드 열두 장을 세로로 쌓음
   └─ MonthCard
      ├─ MonthHeader      달 제목 · 그 달의 공휴일 · 건수
      ├─ WeekdayRow       일 ~ 토, 7칸
      └─ DaysGrid         7칸 격자
         └─ DayCell
            ├─ DayTop     날짜 숫자 · 공휴일 이름 · 「오늘」
            ├─ DayBars    (가로 막대 방식일 때) 기간 항목의 막대 조각
            └─ DayEvents  EventChip을 세로로 나열
```

| 부분 | 내용 | 동작 |
| :--- | :--- | :--- |
| 달 이동 막대 | 왼쪽에 달 버튼 열두 개, 오른쪽에 「오늘」. | 스크롤해도 달력 맨 위에 붙어 있음. 이번 달 버튼은 켜진 모양. 폭이 모자라면 달 버튼 줄을 가로로 밂. |
| 처음 위치 | 한 해 전체를 그려 두고 이번 달이 보이게 함. | 달력을 열면 이번 달 카드로 이동. |
| 달 카드 머리 | 「2026년 11월」, 그 달 공휴일을 알약 배지로, 오른쪽에 건수. | 없음 |
| 요일 줄 | 일요일부터 시작하는 7칸. | 없음 |
| 날짜 칸 | 위에 숫자와 배지, 아래에 그날의 항목. | 칩이 많으면 칸 안에서만 세로 스크롤. |
| 항목 칩 | 첫 줄에 지역·분류 태그, 둘째 줄에 이름(한 줄, 넘치면 말줄임). | 누르면 상세 창을 엶. 호버하면 1px 떠오르고, 마우스를 올리면 줄이지 않은 원래 이름을 보여 줌. |
| 달 밖의 칸 | 앞뒤 빈 칸. 내용 없음. | 없음 |

### 여러 날에 걸친 항목

- **날마다 반복 (기본)**: 기간에 든 날짜 칸마다 같은 칩을 넣습니다.
- **가로 막대 (사용자 선택)**: 시작일부터 종료일까지 칸을 가로지르는 막대 하나로 그립니다. 이름은 시작 칸과 매주 첫 칸에 적습니다. 같은 주에 겹치는 항목은 줄을 나눠 위에서부터 쌓고, 하루짜리 항목은 그 아래에 칩으로 둡니다.
- 전환은 설정의 「기간 항목」에서 합니다.

### 달력 설정

달력을 보는 동안 헤더의 톱니 아이콘에 나오는 항목입니다.

- **이어보기**: 달 카드로 끊지 않고 한 해의 주를 한 장에 이어서 보여 줍니다. 매달 1일 칸에 「11월」 같은 달 표시를 붙이고, 달 이동 버튼은 그 칸으로 갑니다.
- **빈 주 생략**: 항목이 없는 주가 이어지면 한 줄짜리 버튼으로 묶습니다. 버튼에는 기간, 묶인 주의 수, 그 안의 공휴일 수를 적고, 누르면 그 묶음만 펼칩니다. 필터로 걸러서 비게 된 주도 묶습니다.
- **정렬**: 「최신순」을 고르면 늦은 달과 늦은 주가 위로 옵니다. 한 주 안의 요일 순서는 그대로 일요일부터입니다. 리스트의 정렬과 같은 값을 씁니다.
- **칩 내용**: 칩의 첫 줄에 지역과 분류 태그를 보일지 각각 고릅니다. KoreaEvent의 「달력 표시 내용」에서 가져왔고, 거기에는 시각·주최·초댓말·상태도 있습니다.
- 이어보기와 빈 주 생략은 처음에 꺼져 있습니다.

## 점 달력

칸이 좁아 칩의 글자를 읽을 수 없을 때 쓰는 보기입니다. 날짜 칸에는 항목 수만큼 점을 찍고, 날짜를 누르면 그 주 바로 아래로 상세가 펼쳐집니다.

- **언제**: 설정의 「달력 칸」이 「자동」이면 700px 아래에서, 「점」이면 항상. 넓은 화면에서도 설정에서 「점」을 골라 볼 수 있습니다.
- **점**: 항목 하나에 점 하나, 네 개까지 찍고 넘치면 「+2」처럼 적습니다. 진행중은 채운 점, 예정은 빈 점, 종료는 흐린 점입니다.
- **날짜 누르기**: 항목이 있는 날만 누를 수 있습니다. 한 번에 한 날짜만 열립니다. 다른 날을 누르면 앞의 것은 닫히고, 같은 날을 다시 누르면 닫힙니다.
- **상세**: 그 날의 항목을 한 줄씩 나열하고, **한 번에 한 항목만** 아래로 펼쳐 자세히 보여 줍니다. 처음에는 첫 항목이 펼쳐져 있고, 다른 항목을 누르면 앞의 것이 접힙니다.
- **전환**: 날짜 상세와 항목 상세 모두 높이를 0에서 내용 높이까지 0.3초 동안 늘립니다. 항목 줄의 화살표는 펼치면 뒤집힙니다.
- 점 달력에서는 가로 막대를 쓰지 않습니다. 기간 항목도 날마다 점으로 찍습니다.

```text
DaysGrid
├─ DayCell (점)           날짜 숫자 · 점 줄, 누를 수 있음
├─ … 그 주의 일곱 칸 …
└─ DayDetail              그 주의 마지막 칸 뒤, 격자 전체 폭
   ├─ DetailHead          날짜 · 건수 · 공휴일 이름 · 닫기
   └─ Record              한 번에 하나만 펼침
      ├─ RecordHead       지역 태그 · 이름 · 화살표
      └─ RecordBody       이름(원래) · 기간 · 지역 · 분류 · 상태
```

| 부분 | 치수 | 모양 |
| :--- | :--- | :--- |
| 날짜 칸 (점) | 최소 높이 58px | 숫자와 점을 가운데 정렬. 호버하거나 열린 칸은 선택·호버 면. |
| 점 | 7px, 사이 3px | 글자색 원. 예정은 테두리만, 종료는 흐리게. |
| 날짜 상세 | 격자 전체 폭 | 바탕 색, 아래에 1px 선. 머리 줄 0.84rem 굵게. |
| 항목 줄 | 안쪽 9px 14px | 위에 1px 선. 이름은 한 줄, 넘치면 말줄임. 단어 단축이 켜져 있으면 줄인 이름. |
| 항목 상세 | 이름 3.5rem + 나머지 | 왼쪽에 흐린 항목 이름, 오른쪽에 값. 이름은 줄이지 않은 원래 이름. |

## 스타일

| 부분 | 치수 | 모양 |
| :--- | :--- | :--- |
| 달 이동 막대 | 안쪽 8px 12px | 표면 색, 아래에 1px 선. 버튼 높이 30px. |
| 달 카드 | 카드 사이 20px | 표면 색, 1px 테두리, `--r-lg`, 넘치는 부분은 잘라 냄. |
| 달 카드 머리 | 안쪽 10px 16px | 가라앉은 면. 제목 1.08rem 굵게, 건수 0.8rem 흐리게. |
| 요일 칸 | 안쪽 6px | 0.76rem 굵게, 가운데 정렬. |
| 날짜 칸 | 최소 높이 104px, 안쪽 6px | 오른쪽과 아래에 1px 선. 일곱째 칸은 오른쪽 선 없음. |
| 달 밖의 칸 | 최소 높이 72px | 바탕 색으로 한 단계 물러남. |
| 오늘 | 안쪽 2px 테두리 | 칸 안쪽에 굵은 테두리와 「오늘」 알약 배지. 색이 아니라 선으로 구분. |
| 일요일·공휴일 |  | 숫자와 공휴일 이름에 `--day-sun`. 공휴일 이름은 테두리 배지. |
| 토요일 |  | 숫자에 `--day-sat`. |
| 항목 칩 | 안쪽 4px 6px, 칩 사이 4px | 바탕 색, 1px 테두리, `--r-sm`. 이름 0.74rem 굵게. |
| 막대 | 높이 20px, 줄 사이 3px | 선택·호버 면 색, 위아래 1px 선. 칸의 안쪽 여백과 경계선을 넘어 옆 칸과 이어 붙임. 시작과 끝에만 세로 선과 `--r-sm`. |
| 날짜 칸의 칩 목록 | 최대 높이 200px | 넘치면 세로 스크롤. |

700px 아래에서는 기본으로 점 달력으로 바뀝니다. 설정에서 「칩」을 고집하면 칸 안쪽 여백을 3px로 줄이고 칩에는 이름만 남깁니다.

## 확정한 값

| 항목 | 결정 |
| :--- | :--- |
| 요일 색 | 토큰으로 남김 (일요일·공휴일 빨강, 토요일 파랑이 기본값) |
| 여러 날에 걸친 항목 | 기본은 날마다 반복, 사용자가 고르면 가로 막대 |
| 처음 범위 | 한 해 전체 |
| 이어보기 · 빈 주 생략 | 달력의 화면별 설정에서 켜고 끔. 처음에는 꺼 둠 |
| 정렬 | 오래된순이 기본, 최신순으로 거꾸로 볼 수 있음 |
| 좁은 화면 | 점 달력. 날짜를 누르면 그 주 아래로 상세를 펼치고 한 번에 한 항목만 엶 |
| 한 주의 시작 | 일요일 |
