# 편의 기능

`C:\git` 아래 프로젝트에서 사용자를 편하게 해 주는 기능을 찾아 모으고, 기본 화면에 넣을 것을 골랐습니다. 견본 열의 「반영됨」은 이 화면에서 동작하는 것, 「명세만」은 화면 탭에 규칙만 적은 것, 「표시만」과 「발송 제외」는 미리보기 환경 때문에 일부만 동작하는 것입니다.

> 찾은 방법: 웹 프로젝트의 저장 키 이름, 단축키 처리, 파일 머리 설명을 검색했습니다. 대부분 코드 전체를 읽지는 않았기 때문에, 「어디에 있나」는 그 기능이 있는 자리이고 세부 동작은 채택할 때 다시 확인해야 합니다. 안드로이드와 파이썬 프로젝트(TakeYourMark, movie-player-lite, beep-gen)는 화면 구조가 달라 깊이 보지 않았습니다.

## 기본에 넣는 것

기본 화면에 넣기로 정한 기능입니다.

| 기능 | 무엇을 하나 | 어디에 있나 | 견본 |
| :--- | :--- | :--- | :--- |
| 설정 기억 | 설정, 보기 방식, 사이드바 접힘 상태를 브라우저에 저장해 다음에 열 때 그대로. 키 끝에 판 번호를 붙이고, 읽기에 실패하면 기본값으로. | KoreaEvent 축약 설정, Geoje Swimmers 보기 방식·사이드바, haepungdan 테마 | 반영됨 |
| 오류 경계 | 화면 일부가 오류를 내도 전체가 하얗게 비지 않고 안내와 다시 시도 버튼을 보여 줌. | KoreaEvent, KoreaIssue의 AppErrorBoundary | 명세만 |
| 버전 표시와 캐시 갱신 | 패널 하단 블록에 버전과 빌드 날짜 표시. 배포하면 새로 고침 없이 새 파일을 받게 파일 이름에 빌드 표시를 붙임. | KoreaEvent·KoreaIssue의 version.ts, Geoje Swimmers의 `?v=날짜` | 표시만 |
| 새 판 알림 | 서버에 새 판이 올라오면 화면 아래에 「새 버전이 있습니다 · 새로 고침」을 띄움. 설치한 앱이 새 판을 받는 길. 규칙은 [「화면」 규칙](#/column/ai/webapp-common-gui/rules/screen.md)의 「오류 경계와 버전」. | CharQuiz의 update-checker | 명세만 |
| 단축키와 안내 배지 | 숫자 키로 사이드바 탭 전환. Alt를 누르는 동안 버튼 옆에 단축키 배지를 보여 줌. 글자를 입력하는 중에는 동작하지 않음. | html의 keybind-manager | 반영됨 |
| 스크롤 위치 되살리기 | 페이지나 탭을 옮겼다 돌아오면 보던 자리로. | Geoje Swimmers의 shortcut.js | 반영됨 |
| 테마 전환 | 밝게, 어둡게, 스톤, 네이비 네 가지를 기본으로 제공하고 고른 것을 기억. | haepungdan의 테마 기억 | 반영됨 |
| 글자 크기 조절 | 화면 전체의 글자 크기를 몇 단계로 바꿈. | html 변경 이력 달력, janggi 설정 | 반영됨 |
| 단축키 바꾸기 | 사용자가 단축키를 고쳐 쓰고 기억. | 비공개 프로젝트의 useKeybindings | 반영됨 |
| 변경 이력 | 무엇이 언제 바뀌었는지를 문서 정보 페이지에서 보여 줌. | html의 site-history | 반영됨 |
| 의견 보내기 | 질문이나 건의를 보내는 폼. 서버 없이 Web3Forms로 화면에서 바로 발송. | html의 feedback.js | 발송 제외 |
| 로그인 | 로그인 페이지를 부르고 Google 계정을 기본으로 지원. | KoreaEvent, CharQuiz, haepungdan, html | 화면만 |
| 목차 자동 생성 | 본문의 제목을 모아 사이드바 목차를 만들고, 스크롤에 따라 현재 항목을 강조. | html의 toc.js | 반영됨 |
| 공유 복사 알림 | 공유 버튼을 누르면 주소를 복사하고 버튼 아래에 짧은 알림. | KoreaEvent 헤더 | 반영됨 |
| 필터 적용 표시 | 필터가 걸려 있으면 아이콘에 점. | KoreaEvent, KoreaIssue 헤더 | 반영됨 |
| 원래 이름 툴팁 | 말줄임되거나 줄인 이름에 마우스를 올리면 전체 이름. | KoreaEvent 달력 칩 | 반영됨 |
| 홈 화면 설치 | 매니페스트와 아이콘을 넣어 브라우저의 「설치」로 앱처럼 열게 함. 규칙은 [「설치」 규칙](#/column/ai/webapp-common-gui/rules/install.md). | CharQuiz, NameQuiz | 명세만 |

## 선택 기능으로 남긴 것

기본에는 넣지 않고, 필요한 프로젝트가 정해진 자리에 답니다.

| 기능 | 무엇을 하나 | 어디에 있나 | 둘 자리 |
| :--- | :--- | :--- | :--- |
| 통합 검색 | 사이드바 검색 탭에서 제목과 본문을 찾음. 미리 만든 색인 파일을 씀. | html의 search.js | 레일 탭 |
| 내보내기 | 지금 걸러진 목록을 글, 엑셀용 CSV, PDF, 그림으로 저장. | Geoje Swimmers의 exportService | 리스트 요약 줄 |
| 항목 고정 | 자주 보는 항목을 맨 위에 붙여 둠. | Geoje Swimmers | 리스트 행, 카드 |
| 복사 버튼 | 코드나 인용 글 옆의 버튼으로 내용을 복사. | html의 clipboard.js | 본문 |
| 작업 예상 시간 | 오래 걸리는 불러오기를 화면 구석에 알리고, 지난번 걸린 시간으로 남은 시간을 어림. | 비공개 프로젝트의 loadingTracker | 화면 오른쪽 아래 |
| 오늘 하루 보지 않기 | 공지 창에서 고르면 그날은 다시 띄우지 않음. | Geoje Swimmers | 공지 창 |
| 다시 묻지 않기 | 확인 창에서 고르면 같은 질문을 건너뜀. | webpointer | 확인 창 |
| 자료 백업과 복원 | 브라우저에 쌓인 자료를 JSON 파일로 내려받고 다시 올림. | haepungdan의 backup.ts | 설정 |
| 명령 창 | 명령을 이름으로 찾아 실행. | 비공개 프로젝트의 useKeybindings | 단축키 |
| 맨 위로 가기 버튼 | 길게 스크롤하면 오른쪽 아래에 나타나는 버튼. 기존 프로젝트에는 없음. | 새 제안 | 본문 오른쪽 아래 |
| 푸시 알림 | 알림 권한을 받아 예약한 때에 알림. | CharQuiz | 설정 |

## 편집 화면이 있을 때만

| 기능 | 무엇을 하나 | 어디에 있나 |
| :--- | :--- | :--- |
| 실행 취소와 다시 실행 | 편집 기록을 쌓아 되돌리고 다시 적용. | KakaotalkSimulator(최근 50개), webpointer |

| 임시 저장 칸 | 작업을 번호가 붙은 칸에 저장해 두고 불러옴. | webpointer |
| 설정 묶음 저장 | 설정 한 벌을 이름 붙여 저장하고 바꿔 가며 씀. | janggi |

## 찾지 못한 것

- **언어 전환**: 웹 프로젝트에는 구현이 없습니다. 파이썬 프로젝트인 movie-player-lite에만 있습니다. 기본 화면의 언어 설정은 새로 설계해야 합니다.
- **쪽 나누기와 더 보기**: 참조한 세 프로젝트는 목록을 한 번에 그립니다. 더 보기 버튼은 이 문서에서 새로 정한 것입니다.
