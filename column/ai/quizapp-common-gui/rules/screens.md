# 설정·순위·학습현황

설정, 리더보드, 학습현황, 도움말은 `view/setting.html`, `view/leaderboard.html`, `view/progress.html`, `view/help.html`을 받아 **전체 화면 창**(`modal-overlay full-screen`)으로 띄웁니다. 문제를 푸는 동안에는 열리지 않고, ESC를 누르면 닫힙니다.

## 설정

| 묶음 | 항목 |
| :--- | :--- |
| 머리 | 앱 이름, 도구 줄: 앱 설치(설치할 수 있을 때만), 알림함 종(읽지 않은 수 배지), 앱 정보·도움말(i, 새 판이면 new 점), 공유하기, 닫기 |
| 사용자 | 계정 이름과 가린 이메일, 연령대(미상·10대~70대), 성별 |
| 개인화 | 1회당 학습 시간(20~90초 6단), 1회당 문제 수, 자동 진도, 오답 표시, 관전 주기, 복습 알림 |
| 시스템 | 언어(다국어 앱만), 소리(속도·듣기·목소리, 소리 앱만), 테마색(아래 「테마색」), 날씨 반영(처음 화면 무대에 대략의 날씨를 겹칠지, 기본 켬) |
| 단축키 | 동작마다 주 키·보조 키를 다시 정하는 표. 처음에는 접혀 있음 |

- 묶음은 `<details>`로 접고 폅니다(CharQuiz). 앱만의 항목(NameQuiz의 출제 방식, 시즌, 질문 문항 수)은 「개인화」에 둡니다.
- 닫을 때 설정을 저장합니다. 저장 위치는 기기의 `{앱}_CONFIG_{uid}`와 Firestore `users/{uid}`의 앱 설정 필드입니다. 사용자 문서를 퀴즈 앱끼리 공유하므로 필드 이름에 앱 이름을 붙입니다(NameQuiz `namequizConfig`, `namequizConfigUpdatedAt`. CharQuiz만 처음 앱이라 `config`).
- 복습 알림 줄의 상태 글, 권한 허용 단추, 「마지막 예약」 줄은 WebApp Common GUI [「푸시 알림」](#/column/ai/webapp-common-gui/rules/push.md)의 「설정 화면」을 따릅니다.
## 테마색

설정 「시스템」 묶음에 「테마색」 줄을 두어 앱의 **강조색**을 고릅니다(CharQuiz는 언어·음성 속도 다음 줄).

| 견본 | 이름 | `data-accent` | 주 색 |
| :--- | :--- | :--- | :--- |
| 분홍(기본) | 분홍 | `pink` | `#ec4899` |
| 파랑 | 파랑 | `blue` | `#2563eb` |
| 초록 | 초록 | `green` | `#16a34a` |
| 보라 | 보라 | `purple` | `#7c3aed` |
| 주황 | 주황 | `orange` | `#ea580c` |

- 견본은 지름 26px의 동그라미 다섯 개(`role="radiogroup"`, 견본마다 `role="radio"`와 색 이름의 `aria-label`). 고른 것은 `aria-checked="true"`이고 검은 테두리를 두릅니다.
- 누르면 바로 화면 전체에 적용하고 저장합니다. 확인 단추는 없습니다.

### 무엇이 바뀌나

| 바뀜 | 그대로 |
| :--- | :--- |
| 단추, 선택된 칩·탭·범위 단추, 체크·슬라이더(`accent-color`), 콤보 글씨, 배지 테두리, 그라디언트 단추, 옅은 강조 바탕 | 바탕, 글자색, 계절·날씨 무대의 색, 큰 콤보의 금색, 시스템 바(매니페스트 `theme_color`는 흰색 그대로) |

- **밝기 테마가 아닙니다.** WebApp Common GUI의 테마(밝게·어둡게·스톤·네이비, [「화면」](#/column/ai/webapp-common-gui/rules/screen.md))는 바탕과 글자의 밝기를 정하고, 테마색은 그 위에 얹는 **프로젝트 강조색**입니다. 기본 화면이 강조색을 정하지 않고 프로젝트가 얹는다는 WebApp Common GUI의 원칙을 퀴즈 앱에서 사용자가 고를 수 있게 한 것입니다. 두 설정은 따로 저장하고 서로 바꾸지 않습니다.

### 토큰

강조색은 CSS 변수로만 씁니다. **컴포넌트 CSS에 강조색 값을 직접 쓰지 않습니다.**

| 토큰 | 쓰는 곳 | 분홍 값 |
| :--- | :--- | :--- |
| `--accent` | 단추 바탕, 선택 표시, 콤보 글씨 | `#ec4899` |
| `--accent-light` | 그라디언트 위쪽, 밝은 강조 | `#f472b6` |
| `--accent-dark` | 옅은 바탕 위의 강조 글자 | `#be185d` |
| `--accent-deep` | 진한 글자 | `#831843` |
| `--accent-soft` | 옅은 강조 바탕 | `#fdf2f8` |
| `--accent-border` | 옅은 강조 테두리 | `#fbcfe8` |
| `--accent-2` | 그라디언트 끝 | `#f43f5e` |
| `--accent-rgb` | `rgba(var(--accent-rgb), 0.3)` 같은 그림자·반투명 | `236, 72, 153` |

- 값은 `:root`(기본 분홍)와 `html[data-accent="pink|blue|green|purple|orange"]`에 둡니다. 색을 더하려면 이 블록 하나와 견본 하나를 더합니다.

### 저장과 처음 그리기

| 자리 | 값 |
| :--- | :--- |
| 계정 설정 | `userConfig.accentColor`(다른 설정과 함께 저장, 기본 `pink`) |
| 기기 | localStorage `{앱}_ACCENT`. 적용할 때마다 적어 둡니다. |

- `index.html`의 `<head>` 스크립트가 **설정을 읽기 전에** 기기 값으로 `document.documentElement.dataset.accent`를 정합니다. 그래야 다른 색을 고른 사용자에게 기본 분홍이 잠깐 비치지 않습니다.
- 설정을 읽은 뒤 `applyAccentColor(userConfig.accentColor)`가 계정 값을 적용하고 기기 값을 고칩니다. 목록에 없는 값이면 분홍으로 둡니다.

- **공유하기**: 휴대폰의 공유 서랍(`navigator.share`, 제목·소개 글·앱 주소)을 엽니다. 사용자가 서랍을 닫으면 아무 말도 하지 않습니다. 서랍이 없는 브라우저는 앱 주소를 복사하고 「주소를 복사했어요」를 알리고, 복사도 안 되면 주소를 보여 줍니다.
- **앱 설치** 단추의 동작은 [「알림함」](#/column/ai/quizapp-common-gui/rules/inbox.md)의 「홈 화면에 앱 설치」와 같습니다.
- 설정을 열면 톱니의 new 점 가운데 「새 판」 몫이 꺼집니다([「알림함」](#/column/ai/quizapp-common-gui/rules/inbox.md)).

## 리더보드

탭마다 다른 컬렉션을 봅니다. 순위 컬렉션은 앱 이름 접두어(`charquiz_`, `namequiz_`)로 앱마다 나눕니다([「Firebase 준비」](#/column/ai/quizapp-common-gui/rules/firebase.md)). 기간 필터는 없고(전 기간), 범위 고르기 하나만 있습니다.

| 탭 | 컬렉션 | 기록 방식 | 순서 | 열 |
| :--- | :--- | :--- | :--- | :--- |
| 20문제 | `{앱}_speedrun_rankings` | 마칠 때마다 새 문서 `{uid}_{범위}_{ms}` | 정답률 ↓, 걸린 시간 ↑, 10위까지 | 순위, 아이디, 범위(문항 수), 소요시간, 정답률, 완료 시각 |
| 30초 | `{앱}_timeattack_rankings` | 마칠 때마다 새 문서(`correctCount`, `solvedCount`, `accuracy`, `durationSec: 30`) | 맞힌 수 ↓, 정답률 ↓, 먼저 세운 기록, 10위까지 | 순위, 아이디, 범위, 맞힘(푼 수), 정답률, 완료 시각 |
| 학습 | `{앱}_study_rankings` | 사용자·범위당 한 문서 `{uid}_{범위}`. 맞힌 수가 더 많거나, 같고 시간이 짧을 때만 덮어씀 | 맞힌 수 ↓, 걸린 시간 ↑, 10위까지 | 순위, 아이디, 정답수, 소요시간, 정답률, 완료 시각 |
| 힌트 따봉 | 힌트 컬렉션 | [「힌트」](#/column/ai/quizapp-common-gui/rules/hints.md) 「힌트 따봉 순위」 | 받은 따봉 합 ↓ | 순위, 아이디, 받은 따봉, 따봉 받은 힌트 |

- 1~3위는 주황 굵게, 내 줄은 강조합니다. 게스트 이름 `GUEST_xxxx`는 `G_xxxx...`로 줄입니다.
- 범위 이름은 화면에서 짧은 글자로 바꿔 보입니다(CharQuiz: あ, ア, 가, A, a). 여러 범위를 함께 푼 기록은 범위 이름을 `+`로 잇습니다.
- 순위는 누구나 볼 수 있고, **로그인한 사용자만 자기 `uid`로 올립니다**([「처음 화면」](#/column/ai/quizapp-common-gui/rules/home.md) 「게스트와 순위」). 학습 순위는 본인이 자기 문서를 고쳐 쓰고, 그 밖의 고치기·지우기는 관리자(`admins/{uid}`)만 합니다. 30초 순위는 규칙에서 맞힌 수(0~200 정수)와 `durationSec == 30`을 검사합니다.
- 범위·순서 조합마다 Firestore 복합 인덱스가 필요합니다(`firestore.indexes.json`).
- 기록 모드를 마치면 리더보드를 열고 방금 기록을 노란 줄로 한 번 강조합니다(NameQuiz).

## 학습현황

| 부분 | 내용 |
| :--- | :--- |
| 범위 탭 | 지금 묶음의 범위마다 단추(예: 히라가나·가타카나). 묶음에 범위가 하나면 숨김. 처음에는 요약 카드에서 켠 범위를 보이고, 둘 다 켰으면 앞의 것 |
| 최대 콤보 | 맨 위. 기간 단추(주·월·년)와 막대그래프, 「역대 최대 N콤보 · 날짜」. 아래 「콤보 기록」 |
| 응답 속도 분포 | 0.2초 간격 26칸(0~5초 이상). 가장 많은 칸은 진하게 |
| 진행률 | 「진행률: 해금 / 전체 (%)」와 단추 셋: 칸 색 기준 바꾸기(응답속도 ↔ 장기기억), 「모두 해금」(단계 1로), 「모두 초기화」(확인 「경고: … 영구 삭제됩니다」) |
| 항목 표 | 데이터의 줄을 그대로 표로. 해금하지 않은 칸은 회색, 해금한 칸에는 평균 응답(`1.2s`). 복습 때가 된 칸은 빨간 테두리 |

| 누르기 | 동작 |
| :--- | :--- |
| 짧게 | 해금한 칸: 「[あ] 기록을 초기화할까요?」. 해금하지 않은 칸: 「[あ] 진도를 나갈까요?」(단계 1로) |
| 길게(550ms) | 그 항목의 힌트 목록([「힌트」](#/column/ai/quizapp-common-gui/rules/hints.md)) |

## 콤보 기록

학습현황 맨 위에 [Combo](#/column/ai/quizapp-common-gui/rules/quiz.md)의 기록을 보여 줍니다. 예전의 「최근 일주일 학습량」 그래프를 대신합니다(CharQuiz).

| 기간 단추 | 칸 | 값 |
| :--- | :--- | :--- |
| 주 | 최근 7일, 날마다 한 칸 | 그날 한 판에서 가장 길게 이어진 정답 수 |
| 월 | 최근 30일, 날마다 한 칸. 칸이 많아 날짜 글씨는 5일마다(와 마지막 칸)만, 막대 위 숫자는 감춤 | 같음 |
| 년 | 최근 12달, 달마다 한 칸 | 그 달 날마다 값 가운데 최대 |

- 가장 큰 칸을 꽉 차게 그리고 나머지는 비율로 그립니다. 칸에 마우스를 올리면 「날짜: N콤보」를 보입니다.
- **역대 최대**: 판이나 날짜가 바뀌어도 끊기지 않고 이어지는 연속 정답(틀리면 0)의 최댓값과 그 날짜. 없으면 「아직 없음」
- **학습 모드의 답만** 셉니다. 기록 모드와 관전 모드는 세지 않습니다.

| 저장 | 자리 | 규칙 |
| :--- | :--- | :--- |
| 기기 | `{앱}_COMBO_{uid}` = `{ current, best, bestAt, daily: {날짜: 최대} }` | 먼저 적습니다. |
| 날마다 최대 | Firestore `users/{uid}/study_stats/{YYYY-MM-DD}.{앱}MaxCombo` | 이번 판 최대가 저장된 값보다 클 때만 고칩니다. |
| 이어지는 콤보 | Firestore `users/{uid}.{앱}Combo` = `{ current, best, bestAt, updatedAt }` | 읽을 때 기기와 서버 중 큰 `best`를 쓰고, `current`는 더 최근에 적힌 쪽을 씁니다. |

- 사용자 문서와 `study_stats`는 퀴즈 앱끼리 공유하므로 필드 이름에 앱 이름을 붙입니다(CharQuiz `charquizMaxCombo`, `charquizCombo`).

## 학습 시간

- 학습 시간은 기기의 `{앱}_STUDY_STATS_{uid}`(`{날짜: {범위: 초}}`)와 Firestore `users/{uid}/study_stats/{YYYY-MM-DD}`에 더해 둡니다.
- 그림이 있는 앱(NameQuiz)은 표 대신 카드 격자를 쓰고, 카드를 누르면 상세 프로필(그림, 프로필, 대표 힌트, 숙련도, 해금·초기화 단추)을 엽니다.

## 도움말

| 항목 | 규칙 |
| :--- | :--- |
| 여는 곳 | 설정 머리의 i 단추, 단축키 9 |
| 모양 | 전체 화면 창 |
| 맨 위 | 「QuizQuiz 자매품」 링크(아래 「QuizQuiz 자매품」) |
| 맨 아래 판 표시 | 세 줄: 「프로그램 버전」(`window.APP_VERSION`, 예 `CharQuiz v1.0.5`), 「빌드」(`window.CACHE_BUST`), 「QuizApp Common GUI」(`window.QUIZAPP_GUI_VERSION`, 예 `v0.2.0`) |

- 앱이 따르는 QuizApp Common GUI 판은 `index.html`의 `window.QUIZAPP_GUI_VERSION` 한 곳에 적고, 도움말이 그 값을 보여 줍니다. 판을 받아 갈 때 이 값과 앱 쪽 기록([「판 이력」](#/column/ai/quizapp-common-gui/rules/changes.md))의 「확인한 판」을 같이 올립니다.

### QuizQuiz 자매품

도움말 맨 위에 다른 퀴즈 앱으로 가는 링크를 둡니다(`components/sister-apps.js`). 예전에는 알림함 맨 위에 있었는데, 알림을 볼 때마다 홍보가 끼어들지 않도록 도움말로 옮겼습니다.

| 항목 | 규칙 |
| :--- | :--- |
| 제목 | 「QuizQuiz 자매품」 |
| 목록 | Firestore `quiz_apps` 컬렉션의 앱 가운데 **이 앱을 뺀** 나머지, `active`가 켜진 것만, `order` 순. 한 줄에 앱 아이콘, 이름, 한 줄 소개, 새 창 표시 |
| 누르면 | 새 탭으로 그 앱을 엽니다. |
| 그리는 순서 | 기기에 저장해 둔 마지막 목록으로 먼저 그리고, `quiz_apps`에서 새로 받아 다시 그립니다. 한 번도 받지 못했고 DB도 열리지 않으면 앱에 넣어 둔 기본 목록을 씁니다. |
| 이 앱 | `sister-apps.js`의 `CURRENT_APP`에 이 앱의 `id`를 적습니다. |

`quiz_apps/{id}` 문서 하나가 앱 하나입니다.

| 필드 | 뜻 |
| :--- | :--- |
| `id` | 앱 이름(문서 ID와 같음). 예 `CharQuiz` |
| `name` | 보여 줄 이름. 예 「글자 퀴즈」 |
| `desc` | 한 줄 소개 |
| `url` | 앱 주소. `https://`로 시작해야 보입니다. |
| `icon` | 아이콘 주소. 비우면 `{url}icon-192.png` |
| `order` | 보이는 순서(작은 수가 위) |
| `active` | `false`면 숨김 |

- 새 퀴즈 앱을 내면 **앱 코드는 고치지 않고** `quiz_apps`에 문서 하나만 더합니다. 규칙은 누구나 읽기, 쓰기는 관리자만이라 콘솔에서 더합니다.
