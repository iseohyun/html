# 처음 화면

앱을 열면 헤더 아래에 모드 카드가 놓입니다. 카드 하나를 누르면 그 모드가 본문(`#main-box`)에서 시작되고, 끝나면 이 화면으로 돌아옵니다.

## 헤더

| 자리 | 요소 |
| :--- | :--- |
| 왼쪽 | 프로필 아이콘(로그인하면 제공자 칩 G/K/N) + 이름 + 「님」. 누르면 로그인 창(단축키 ESC) |
| 가운데 | 문제를 푸는 동안만: 모드 배지, 일시정지, 중단(✕) |
| 오른쪽 | 리더보드(5), 학습현황(3, 복습 대기 수 배지), 범위 바꾸기(1), 설정 톱니(4, new 점). NameQuiz는 출제 방식(2)과 알림함 종이 더 있습니다. |

- 괄호 안은 단축키입니다. Alt를 누르는 동안 단추에 단축키 배지가 보입니다.
- **복습 대기 수 배지**: 지금 묶음(언어)의 **모든 범위**에서 복습할 때가 된 항목 수. 요약 카드에서 꺼 둔 범위도 셉니다(학습에 함께 나오므로). 0이면 숨깁니다.
- 문제를 푸는 동안에는 헤더 오른쪽 메뉴를 숨기고, 리더보드·설정 같은 창도 열리지 않습니다.

## 모드 카드

| 카드 | 설명 문구(예) | 단축키 | 하는 일 |
| :--- | :--- | :--- | :--- |
| 학습 모드 | 「반복 오디오 퀴즈로 가나 익히기」 | Q | 간격 반복으로 정해진 시간 동안 풉니다. 진도와 학습 순위를 저장합니다. |
| 기록 모드 | 둘로 나뉜 카드: 왼쪽 「20문제 타임어택」, 오른쪽 「30초 타임어택」 | W(왼쪽) | 속도를 재서 순위에 올립니다. |
| 관전 모드 | 「자동 재생으로 편안하게 복습」 | E | 풀지 않고 자동으로 넘겨 보며 복습합니다. 저장하지 않습니다. |
| 학습범위 요약 카드 | 아래 「학습범위 요약 카드」 | — | 범위를 고르고 해금 정도를 봅니다. |

### 학습 모드

| 항목 | 규칙 |
| :--- | :--- |
| 시간 | 설정의 「1회당 학습 시간」(20·30·40·50·60·90초, 기본 60초) |
| 시간이 다 되면 | 「⏰ 시간 만료! 마지막 문항 정산 중...」을 띄우고, **지금 문제까지 풀면** 끝냅니다. |
| 문제 풀 | 설정의 「1회당 문제 수」(기본 10). 범위를 여럿 고르면 범위마다 `max(4, ceil(풀 크기 ÷ 범위 수))`개씩 뽑아 합칩니다. 꺼 둔 범위의 복습 항목도 더합니다([「문제 화면」](#/column/ai/quizapp-common-gui/rules/quiz.md) 「복습은 항상 포함」). 넘치면 복습 항목을 먼저 남기고 자릅니다. |
| 끝나면 | 처음 화면 → [학습 결과표](#/column/ai/quizapp-common-gui/rules/result.md) → 복습 알림 예약 → 진도 저장 → 학습 시간 저장 → 학습 순위 등록 |
| 학습 순위 | 맞힌 수, 걸린 시간, 정답률. 맞힌 수가 0이면 올리지 않습니다(NameQuiz 방식). **로그인한 사용자만** 올립니다(아래 「게스트와 순위」). |

### 기록 모드: 20문제 타임어택

| 항목 | 규칙 |
| :--- | :--- |
| 문제 | 고른 범위의 **모든 항목**(해금과 상관없이)을 섞어 앞에서 20개. 항목이 20개보다 적으면 그 수만큼 |
| 시간 | 0초부터 올라갑니다. 표시 「진행률: n / 20 \| ⏱️ 00:00」 |
| 끝 | 20문제를 다 풀면 끝. 중단(✕)하면 순위에 올리지 않습니다. |
| 결과 창 | 끝까지 풀면 걸린 시간을 크게, 아래에 「20문제 · 맞힘 n개 · 정답률 n%」를 보여 줍니다. |
| 순위 | 정답률이 높은 순, 같으면 걸린 시간이 짧은 순 |
| 진도 | 이미 해금된 항목만 채점 결과를 반영합니다. |

### 기록 모드: 30초 타임어택

| 항목 | 규칙 |
| :--- | :--- |
| 문제 | 20문제와 같은 풀. 같은 항목이 연달아 나오지 않게 합니다. |
| 시간 | 30초에서 줄어 0이 되면 바로 끝. 표시 「⏱️ n초 \| ✅ 맞힘 / 푼 수」 |
| 결과 창 | 「N개 맞힘」과 「푼 문제 n개 · 정답률 n%」. 중간에 그만두면 「중간에 그만둔 기록은 순위에 올리지 않습니다.」를 덧붙입니다. |
| 순위 | 시간을 다 쓰고 한 문제 이상 풀었고 로그인했을 때만. 맞힌 수 → 정답률 → 먼저 세운 기록 순 |
| 진도 | 해금된 항목 중 이번에 나온 것만 저장합니다. |

### 게스트와 순위

두 앱 공통 규칙입니다. 게스트(로그인하지 않은 사용자)도 학습 모드와 기록 모드를 그대로 할 수 있고 진도도 저장됩니다. 다만 **순위에는 올리지 않습니다.** 순위를 보내기 전에 로그인 여부(`canSubmitRanking()` = `auth.currentUser`가 있음)를 확인합니다.

| 경우 | 안내 |
| :--- | :--- |
| 결과 창이 있는 끝(학습 결과표, 20문제·30초 결과 창) | 결과 창 아래에 「게스트 기록은 리더보드에 올라가지 않아요. 로그인하면 다음 기록부터 순위에 올라갑니다.」와 「로그인」 단추. 30초는 시간을 다 썼을 때만 |
| 결과 창이 없는 기록 모드를 끝까지 풂(NameQuiz의 그림·이름·교차, 질문 기록 모드) | 같은 문구의 「🏆 순위 안내」 창과 「로그인」 단추 |
| 결과 창이 없는 학습 모드(NameQuiz) | 한 문제 이상 풀고 끝냈을 때 같은 「순위 안내」 창. **앱을 열 때마다 한 번만** 띄웁니다. |
| 중간에 그만둠 | 안내하지 않습니다(순위에 오를 기록이 아님). |

- 「로그인」 단추는 안내를 닫고 로그인 창을 엽니다. 지금 기록은 올리지 않습니다.
- 앱이 보내지 않는 것과 별도로 Firestore 규칙이 막습니다. 순위 문서는 로그인한 본인 `uid`로만 만들 수 있고, 학습 순위는 본인 문서만 고칠 수 있습니다([「Firebase 준비」](#/column/ai/quizapp-common-gui/rules/firebase.md)).

### 관전 모드

| 항목 | 규칙 |
| :--- | :--- |
| 풀 | 고른 범위에서 기록이 있는 항목을 평균 응답이 느린 순으로 10개. 기록이 없으면 데이터 앞의 10개 |
| 넘기기 | 설정의 관전 주기(기본 1초)마다 하나를 크게 보여 줍니다. 같은 항목을 연달아 고르지 않습니다. 소리가 있는 앱은 읽어 줍니다. |
| 끝 | 학습 시간이 지나면 끝. 진도·순위를 저장하지 않습니다. |

## 학습범위 요약 카드

범위가 여러 개인 앱에서 모드 카드 옆에 둡니다. 범위를 묶음(CharQuiz는 언어: 일본어 = 히라가나·가타카나, 한국어 = 한글, 영어 = 대문자·소문자)으로 나눠 보여 줍니다.

| 요소 | 규칙 |
| :--- | :--- |
| 제목 | 지금 묶음의 이름(예: 「일본어」) |
| 범위 단추 | 묶음 안의 범위마다 하나. 고른 것은 진하게(`aria-pressed="true"`), 나머지는 음영 |
| 해금 정도 | 「**해금 수 / 전체** (0.0%) 해금」. 해금 = 진도 단계가 1 이상 |
| 고르기 | 단추를 누르면 그 범위를 더하거나 뺍니다. 여러 개를 함께 고를 수 있고, **마지막 하나는 뺄 수 없습니다.** |
| 묶음 바꾸기 | 헤더의 범위 단추(단축키 1)가 묶음을 차례로 돕니다. 바꾸면 그 묶음의 첫 범위 하나만 고른 상태가 됩니다. |
| 저장 | 사용자 설정의 `activeDomains`(고른 범위 목록). 첫 범위가 `currentDomain` |

- 여러 범위를 한 풀에 넣으면 문제 ID가 겹칠 수 있으므로 `범위 순서 × 1000 + 원래 ID`를 풀 안의 ID로 쓰고, 저장할 때는 원래 ID(`srcCharId`)로 되돌립니다.

## 계절·날씨 무대

학습범위 요약 카드의 바탕에 고른 범위의 항목(글자)들이 계절에 맞게 움직이는 무대를 깝니다(`components/season-weather.js`, `components/letter-stage.js`).

| 항목 | 규칙 |
| :--- | :--- |
| 계절 | 기기 날짜로 정합니다. 3~5월 봄, 6~8월 여름, 9~11월 가을, 12~2월 겨울 |
| 움직임 | 고른 범위의 항목 가운데 최대 10개. 봄은 살랑이며 떠오르고 꽃잎, 여름은 물결 위에서 출렁이고 윤슬, 가을은 흔들리며 내려오고 낙엽, 겨울은 천천히 내려오고 눈 |
| 날씨 | 그 위에 겹칩니다. 비·뇌우는 빗줄기(뇌우는 가끔 번쩍), 눈은 눈송이, 흐림은 구름, 안개는 뿌연 막, 맑음은 해(밤에는 별) |
| 배지 | 카드 위에 「🌸 봄 · ☀️ 맑음 12°」 같은 배지. 누르면 계절이 봄 → 여름 → 가을 → 겨울로 바뀝니다(그 화면에서만, 저장하지 않음). |
| 멈춤 | 카드가 화면에서 사라지면 그리기를 멈춥니다. 「동작 줄이기」(`prefers-reduced-motion`)가 켜져 있으면 한 장면만 그립니다. |

날씨는 위치 권한을 묻지 않고 **접속 IP로 대략** 짐작합니다.

1. `https://ipwho.is/`에서 도시 단위의 위도·경도를 받습니다.
2. 좌표를 **소수 한 자리**(약 10km)로 줄여 Open-Meteo(`api.open-meteo.com`)에서 지금 날씨 코드·낮밤·기온을 받습니다. 둘 다 키가 필요 없습니다.
3. 결과(실패하면 「없음」)를 기기에 **1시간** 저장해 다시 씁니다(`{앱}_WEATHER`). 요청마다 6초 제한, 실패하면 계절만 씁니다.
4. 설정의 「날씨 반영」을 끄면 아예 묻지 않습니다. 접속 IP가 바깥 서비스로 가기 때문에 끌 수 있게 둡니다.

| 날씨 코드(WMO) | 화면 |
| :--- | :--- |
| 0, 1 | 맑음 |
| 2, 3 | 흐림 |
| 45, 48 | 안개 |
| 51~82(눈 제외) | 비 |
| 71~77, 85, 86 | 눈 |
| 95 이상 | 뇌우 |

## 모드를 시작할 때

1. 이미 시작 중이면 다시 시작하지 않습니다(두 번 누르기 막기).
2. 앞 모드의 타이머와 소리를 멈춥니다.
3. 문제 화면(`view/studyMode.html`, 관전은 `view/spectatorMode.html`)을 캐시 버스팅 표시(`?v=`)를 붙여 받아 본문에 넣습니다.
4. 헤더 오른쪽 메뉴를 숨기고, 가운데에 모드 배지(「학습 모드」, 「20문제 타임어택」, 「30초 타임어택」, 「관전 모드 (LIVE)」), 일시정지, 중단을 보입니다.

## 아직 확정하지 않은 값

| 항목 | 임시 결정 |
| :--- | :--- |
| 30초 타임어택 단축키 | 없음(CharQuiz). 새 앱은 W를 20문제, 단축키 없이 30초 |
| 기록을 마친 뒤 | 결과 창(CharQuiz). 리더보드를 열고 방금 기록을 노란 줄로 강조하는 NameQuiz 방식과 어느 쪽을 기본으로 할지 |
| 계절·날씨 무대 | CharQuiz만. 그림 앱(NameQuiz)은 더블클릭으로 계절을 바꾸는 캐릭터 무대(`seasonal-stage.js`)가 따로 있음 |
| 범위가 하나뿐인 앱 | 요약 카드 대신 안내 카드(앱 이름·범위 이름·해금 정도) |
