# 힌트

항목마다 외우는 요령을 모아 둡니다. 앱이 넣어 둔 **기본 힌트**와 사용자가 올리는 **사용자 힌트**가 있고, 다른 사람의 힌트에 따봉(👍)을 줄 수 있습니다.

## 여는 곳

| 자리 | 동작 |
| :--- | :--- |
| 문제 화면의 💡 | 학습 모드에서만 보입니다. 누르면 **시간을 멈추고**(소리도 멈춤) 지금 문제의 힌트 목록을 엽니다. 닫으면 시간이 다시 흐르고 문제를 다시 읽어 줍니다. 시간이 이미 끝났으면 열리지 않습니다. |
| 학습현황에서 항목 길게 누르기 | 550ms 동안 누르고 있으면 그 항목의 힌트 목록을 엽니다. 누르는 동안 10px 넘게 움직이면 취소합니다. |
| 상세 프로필의 대표 힌트 | 카드 격자를 쓰는 앱(NameQuiz)만. 아래 「대표 힌트」 |

길게 누르기의 세부:

- `pointerdown`에서 타이머를 걸고, `pointerup`, `pointercancel`, `pointerleave`에서 취소합니다.
- 길게 누른 칸에는 우클릭 메뉴(휴대폰의 길게 누르기 메뉴)를 띄우지 않습니다.
- 길게 누른 뒤 따라오는 클릭 한 번은 무시합니다. 그래야 짧게 누르기 동작(초기화·해금 묻기)이 같이 뜨지 않습니다.

## 목록 창

머리는 「💡 {항목} 힌트」입니다.

| 칸 | 내용 |
| :--- | :--- |
| 내 칸(맨 위) | 내 힌트가 있으면 글과 「내 힌트 · 👍 n」, 수정·삭제. 없으면 입력칸 「내 힌트 올리기 (글자마다 하나)」와 `n / 80` 글자 수 |
| 비로그인 | 입력칸 대신 「로그인하면 나만의 힌트를 하나 올릴 수 있어요.」 |
| 목록 | 다른 사람의 힌트와 기본 힌트. 따봉 많은 순, 같으면 최근에 고친 순. 기본 힌트는 따봉 0으로 치고, 같은 따봉이면 사용자 힌트보다 앞 |
| 기본 힌트 | 「기본 힌트」 표시. 따봉 단추 없음 |
| 따봉 단추 | 「👍 n」. 누르면 켜고 끕니다. 비로그인이거나 내 힌트면 누를 수 없습니다. |

- 삭제는 「내 힌트를 삭제할까요? 받은 따봉도 함께 사라집니다.」로 확인합니다.

## 사용자 힌트 규칙

| 항목 | 규칙 |
| :--- | :--- |
| 개수 | **사용자 한 명이 항목마다 1개.** 문서 ID를 `{범위}__{항목}__{uid}`로 정해 규칙이 둘째 문서를 막습니다. |
| 길이 | 글 1~80자(`HINT_MAX_LENGTH`), 작성자 이름 30자까지(헤더 이름에서 괄호 앞) |
| 고치기 | 글과 이름만. 따봉은 그대로 |
| 지우고 다시 올리기 | 새 판 번호(`rev`, 무작위 8자)를 받아, 예전 글에 받은 따봉은 이어지지 않습니다. |
| 지우기 | 작성자나 관리자 |

## 따봉 규칙

- 따봉 한 번은 따봉 문서 하나(`{힌트ID}__{rev}__{uid}`)와 힌트의 `likeCount` ±1을 **한 번의 일괄 쓰기**로 합니다.
- 내 힌트에는 따봉을 줄 수 없습니다.
- 규칙이 따봉 문서가 생기면 +1, 사라지면 −1만 허락합니다. 힌트가 지워졌거나 `rev`가 바뀐 따봉 문서는 그냥 지울 수 있습니다.

## 힌트 따봉 순위

리더보드의 「힌트 따봉」 탭입니다.

1. `likeCount > 0`인 힌트를 따봉 많은 순으로 500개 읽습니다.
2. 작성자(`uid`)마다 받은 따봉 합과 따봉 받은 힌트 수를 모읍니다.
3. 따봉 합 ↓, 힌트 수 ↓ 순으로 20명. 이름은 그 사람이 가장 최근에 고친 힌트의 작성자 이름
4. 비었으면 「아직 따봉을 받은 힌트가 없어요. 첫 주인공이 되어 보세요!」

## 기본 힌트

`components/hint-seeds.js`에 둡니다. 열쇠는 항목(CharQuiz는 글자, NameQuiz는 한글 이름)입니다.

- 바탕 항목에서 만들 수 있는 힌트는 코드로 만듭니다. CharQuiz는 탁점·반탁점 글자에 「{바탕 글자}에 탁점(゛)을 찍으면 탁한 소리」 한 줄을 붙입니다.
- 기본 힌트가 없는 범위(CharQuiz의 한글·영문)는 사용자 힌트만 보입니다.

## 대표 힌트

상세 프로필에 힌트 하나를 보여 주는 앱만 씁니다.

1. 따봉을 받은 사용자 힌트 가운데 1등
2. 없으면 기본 힌트
3. 그것도 없으면 가장 최근의 사용자 힌트

- 5분 동안 기억해 두고(`TOP_HINT_CACHE_TTL_MS`), 힌트를 저장·삭제하거나 따봉을 주면 지웁니다. 전구 단추로 목록 창을 엽니다.

## 저장 구조

| 컬렉션 | 문서 ID | 필드 |
| :--- | :--- | :--- |
| `{앱}_hints`(`char_hints`, `name_hints`. 새 앱은 앱 이름 접두어) | `{범위}__{항목}__{uid}` | `charKey`(`{범위}__{항목}`), `domain`, 항목(`char` 또는 `koName`), `uid`, `authorName`, `text`, `likeCount`, `rev`, `createdAt`, `updatedAt` |
| `{앱}_hint_likes` | `{힌트ID}__{rev}__{uid}` | `hintId`, `rev`, `uid`, `charKey`, `createdAt` |

`firestore.rules`가 지키는 것:

- 힌트는 누구나 읽고, 따봉 문서는 본인 것만 읽습니다.
- 만들기: 로그인, 정해진 필드만, `uid`가 나, 범위가 앱의 범위 목록 안, `charKey`와 문서 ID가 위 모양, 글 1~80자, `likeCount == 0`, `rev` 1~20자
- 고치기: 작성자는 `text`, `authorName`, `updatedAt`만. 다른 사람은 `likeCount`만 ±1이고, 같은 일괄 쓰기에서 따봉 문서가 생기거나 사라져야 합니다.
- 새 앱은 범위 목록과 항목 필드 이름을 바꿉니다.
