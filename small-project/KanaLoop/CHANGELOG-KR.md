# KanaLoop 변경 이력 (Changelog)

KanaLoop 일본어 가나 학습 어플리케이션의 버전별 변경 사항 기록 문서입니다.

## [v1.0.3] - 2026-08-24
### 주요 변경 및 개선 사항 (퀴즈 레이아웃 100% 뷰포트 적합화, 일시정지 엔진, 팝업 간소화 & 모달 네비게이션)
- **퀴즈 모드 4지선다 보기 100% 출력 보장 (하단 잘림 완벽 해결)**:
  - `.options-grid`를 가변 2x2 반응형 그리드(`grid-template-rows: repeat(2, 1fr)`, `clamp(1.8rem, 5vh, 2.8rem)`)로 전면 개편하여 모바일 및 낮은 해상도에서도 하단 보기 2개가 절대 잘리지 않도록 보장.
  - `studyMode.html` 충돌 인라인 스타일 정리 및 `#main-box`, `#audio-trigger` 여백 컴팩트 최적화.
- **퀴즈 일시정지(Pause) / 재개(Resume) 토글 엔진 및 팝업 알림 제거**:
  - 일시정지 버튼 클릭 시 타이머가 정지되고 플레이(`play_arrow`) 아이콘으로 전환되며, 재클릭 시 음성 재생과 함께 세션이 매끄럽게 재개되도록 개선.
  - 세션 마감 시 학습 흐름을 방해하던 브라우저 `alert()`, `prompt()`, 자동 리더보드 강제 팝업을 제거하여 백그라운드 무중단 데이터 동기화로 전환.
- **상단 헤더 및 모달 UX 개선**:
  - 환경설정 모달 헤더에 도움말(`?`) 아이콘을 배치하고, 도움말 닫기 시 환경설정으로 자동 복귀하는 네비게이션 체계 구축.
  - 메인 상단 헤더에서 도움말 항목을 제거하고, 환경설정 아이콘(`popupSetting`)을 가장 우측 끝으로 재배치.
  - SVG 파비콘 링크 추가로 `/favicon.ico` 404 오류 제거.
- **FCM 푸시 알림 서비스 워커 안정화**:
  - `notification-handler.js`에서 `navigator.serviceWorker.ready` 상태를 대기한 후 토큰을 발급하도록 수정하여 PushManager AbortError 해결.
  - `firebase-messaging-sw.js`에 `skipWaiting` 및 `clients.claim` 수명주기 이벤트 추가.

## [v1.0.2] - 2026-08-08
### 주요 변경 및 개선 사항 (Local-First 백엔드 통신 최적화 & 모달 UI 고도화)
- **Local-First (Browser-First) 통신 최적화 아키텍처 수립**:
  - **0ms 초고속 로컬 캐싱 기동**: 브라우저 `localStorage` 기반으로 데이터를 0ms 복원하여 불필요한 서버 DB 읽기(Read) 쿼리를 최대 100% 절감.
  - **세션 지연 배치 동기화 (Lazy Batch Sync)**: 퀴즈 진행 중 정산 시 발생하던 DB 쓰기 쿼리를 0회로 무력화하고, 10문제 세션 종료 시점에만 `writeBatch` 1회로 모아서 서버에 전송 (DB 쓰기 비용 90% 이상 절감).
  - **양방향 스마트 병합 (Smart Bidirectional Merge)**: 서버 DB의 기존 학습 내역과 로컬 학습 데이터를 단어(CharID) 단위로 최신 타임스탬프 정밀 비교/병합하여 데이터 100% 복원 보장.
  - **파이어베이스 보안 규칙 예외 방어**: `users/{uid}` 메인 문서 연동 및 Self-Healing Fallback 기법을 적용해 네트워크/권한 오류 시에도 화면 튕김 차단.
- **모달 UI / UX 디테일 개선**:
  - **모달 헤더 구조화 (`.modal-header`)**: 모달 팝업 최상단에 타이틀과 닫기 버튼을 Flex 수평 배치하여, 닫기 버튼(`&times;`)이 본문 텍스트나 설정 컴포넌트와 절대로 겹치지(overlap) 않도록 전면 개선.
  - **모달 세로 스크롤바 디자인 숨김**: 크로스 브라우저 스크롤바 막대(`::-webkit-scrollbar`)를 디자인적으로 감추어 정갈한 뷰 제공 (스크롤 동작은 기존과 동일 유지).

## [v1.0.1] - 2026-08-08
### 주요 변경 및 개선 사항 (디자인 시스템 전면 리뉴얼 및 3D 카드 UI 적용)
- **현대적 디자인 시스템 (Modern Design System) 도입**:
  - **글래스모피즘 상단 헤더 (`.user-profile-box`)**: 촌스러운 배경색을 은은한 반투명 유리 질감(`backdrop-filter: blur(14px)`)과 미세 경계선으로 리뉴얼.
  - **3D 인터랙티브 모드 선택 카드 (`#mode-selection-layer`)**: 밋밋한 검은색 정사각 버튼을 3D 입체 그라데이션 카드(학습: 딥블루/에메랄드, 기록: 코랄오렌지, 관전: 딥퍼플) 및 서브 텍스트/모드 아이콘 구조로 고도화.
  - **타이포그래피 개선**: 구글 폰트(`Outfit`, `Noto Sans KR`, `Noto Sans JP`)를 연동하여 한글 및 가나(히라가나/카타카나) 글자 가독성 강화.
  - **모달 및 뱃지 스타일링**: 둥근 모서리(`border-radius: 24px`), 섀도우, 애니메이션 페이드인 및 입체 뱃지 연동.
- **자바스크립트 템플릿 동기화 및 버그 조치**:
  - `main.js` 내 `MAIN_SELECTION_HTML` 동적 주입 템플릿을 신규 3D 카드 구조로 완벽히 동기화.
  - `.mode-btn` 기본 CSS 배경 fallback을 추가하여 예외 상황에서도 회색 렌더링을 차단.
