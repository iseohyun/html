# 변경 이력 (CHANGELOG-KR.md)

이 문서는 카카오톡 대화 생성기 소프로젝트의 버전별 주요 변경 사항 및 업데이트 내역을 기록합니다.

## [v1.3.5] - 2026-08-09
- **대화 파일 로드 시 대화 범위(`1 ~ totalCount`) 및 진행 슬라이더 100% 자동 재조정 연동**:
  - 사용자 대화 내보내기 파일 선택 로딩 시, 이전 `1 ~ 2` 범위 고정 현상을 제거하고 불러온 대화의 전체 개수(`totalCount`, 예: 3,192개)에 맞춰 `startRangeIndex = 1`, `endRangeIndex = totalCount`로 범위 라벨 및 진행률 슬라이더가 100% 자동 동기화 조절되도록 완벽 구현.

## [v1.3.4] - 2026-08-09
- **`applySettingsToUI` DOM 안전 가드 적용 및 네트워크 404 콘솔 로그 완전 소멸**:
  - `applySettingsToUI` 내의 모든 DOM 프로퍼티 대입부(`input-capture-time`, `input-battery`, `input-bg-color` 등)에 `if (el)` 안전 검사 가드를 장착하여 `TypeError: Cannot set properties of null` 런타임 크래시 100% 완전 완치.
  - `loadDefaultData` 시 존재하지 않는 404 경로 fetch 시도를 소거하고 순수 인메모리 기본 데이터(세로 2340px)로 직통 렌더링 전환하여 브라우저 개발자 콘솔 404 빨간색 네트워크 로그 영구 소멸.

## [v1.3.3] - 2026-08-09
- **대화내용 불러오기 버튼 100% 동작 보장 및 OS 탐색기 기본 필터 모든 파일(*.*) 전환**:
  - HTML 파일 로더(`<input type="file" id="file-loader">`)의 `accept` 속성을 완전히 소거하여 윈도우 OS 파일 탐색기 창이 열릴 때 기본 필터가 **"모든 파일 (*.*)"**로 즉시 설정되도록 전환.
  - **[대화내용 불러오기]** 버튼 클릭 이벤트 수신기 강화 (`e.preventDefault()`, `fileLoader.value=''` 사전 초기화 후 `fileLoader.click()` 100% 호환 호출).

## [v1.3.2] - 2026-08-09
- **대화진행률 0/0개 미출력 및 캔버스 요소 렌더링 무효화 버그 수정**:
  - 파일 로드 시 대화진행률 슬라이더(`#input-progress`)의 `value` 기본값이 `-1`/`0`으로 구속되어 캔버스 렌더링 출력이 전면 스킵되던 현상 완전 해결.
  - 파일 로딩 즉시 `progressEl.value = totalCount` (3,192개)로 100% 자동 풀 로딩 대입되어 배터리, 와이파이, 채팅방 이름 및 전체 대화방 캔버스 드로잉 정상 가동.

## [v1.3.1] - 2026-08-09
- **대화 내보내기 파일 로딩 & 정규식 파싱 엔진 버그 수정**:
  - `index.html` 파일 로더의 `accept` 제한을 `*`로 변경하여 확장자가 없는 파일(예: `정재현... 대화`) 및 모든 텍스트 파일 100% 선택 지원.
  - 시간 표기가 결합된 날짜 헤더(`2022년 7월 8일 오후 1:24`) 파싱 정규식 교정 및 개행 멀티라인 메시지 연속 연결 처리 패치 (3,192개 대화 100% 완벽 로드).

## [v1.3.0] - 2026-08-09
- **대화방 테마 단일화 및 실시간 미니 프리뷰 색상 상세 설정 모달 도입**:

    - 모달 우측에서 7대 세부 색상(배경, 내말풍선, 내글씨, 상대말풍선, 상대글씨, 상대닉네임, 시간, 날짜)을 개별 조정 후 [적용] 시 '사용자 지정(Custom)'으로 자동 이관 및 메인 캔버스 100% 반영.
