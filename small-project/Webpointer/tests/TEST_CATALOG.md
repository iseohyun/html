# Webpointer Test Catalog & Test Execution Guide

## 1. Zero-Dependency In-Browser Test Runner (무설치 브라우저 러너)
Playwright나 Node CLI 설치 없이, **웹 브라우저에서 즉시 모든 TC를 실행**할 수 있습니다.

### 실행 방법:
1. 웹 서버가 구동 중인 상태에서 브라우저(Chrome, Edge 또는 Antigravity `/browser` 모드)로 다음 주소에 접속합니다:
   ```
   http://localhost:8080/tests/index.html
   ```
2. **[▶ 전체 실행]** 버튼을 클릭하면 12개 모듈러 스위트(총 107개 TC)가 실시간으로 자동 실행되며 Pass/Fail 상태가 시각적으로 표시됩니다.
3. 상단 검색창에 `S02_TC06`, `S08`, `색상`, `정렬` 등을 입력하여 특정 테스트만 실시간 필터링하여 실행할 수 있습니다.
4. **[🧹 전체 초기화]** 및 **[📋 전체 에러 복사]** 버튼으로 테스트 결과 리셋과 실패 로그 일괄 복사가 가능합니다.

## 3. 다이렉트 테스트 호출 규약
- AI에게 `"웹포인터:S02_TC06 확인해줘"` 또는 `"Webpointer:S08_TC04 확인해줘"`라고 요청하면:
  - 브라우저 러너 또는 CLI를 통해 즉시 해당 스위트의 테스트를 타겟 실행하고 결과를 보고합니다.
