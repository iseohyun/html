# Webpointer Test Catalog & Test Execution Guide

## 1. Zero-Dependency In-Browser Test Runner (무설치 브라우저 러너)
Playwright나 Node CLI 설치 없이, **웹 브라우저에서 즉시 모든 TC를 실행**할 수 있습니다.

### 실행 방법:
1. 웹 서버가 구동 중인 상태에서 브라우저(Chrome, Edge 또는 Antigravity `/browser` 모드)로 다음 주소에 접속합니다:
   ```
   http://localhost:8080/tests/index.html
   ```
2. **[▶ 전체 실행 (Run All)]** 버튼을 클릭하면 모든 모듈러 스위트(7개 스위트)가 실시간으로 자동 실행되며 Pass/Fail 상태가 시각적으로 표시됩니다.
3. 상단 검색창에 `TC60`, `색상`, `정렬` 등을 입력하여 특정 테스트만 실시간 필터링하여 실행할 수도 있습니다.

## 2. 모듈러 테스트 스위트 구조 (`tests/suites/`)

| :--- | :--- | :--- | :--- |
| **`suite-01-basic.js`** | 기본 환경 & 도구 | `TC01` ~ `TC06` | 캔버스 초기화, 뷰포트, 리본 탭/카테고리 토글, 팔레트 모달, 도구 전환, DOM 렌더링 무결성 |
| **`suite-02-shapes.js`** | 도형 & 직교 스냅 | `TC07`, `TC38`~`TC41`, `TC60` | 기본 도형, 호(Arc) 핸들러, 회전 상자, 미채움 호 자석선택, 직선 Ctrl 가로/세로 직교 스냅 |
| **`suite-03-styles.js`** | 스타일 & 색상 롱프레스 | `TC08`, `TC19`, `TC20`, `TC25`, `TC26`, `TC28`, `TC61` | 선/면/글자 서식, 필터 효과, 그라디언트, 색상 단독 적용 & 200ms 롱프레스 팔레트 팝오버 |
| **`suite-04-text.js`** | 글 서식 & 정렬/AutoFit | `TC09`, `TC15`, `TC27`, `TC42`~`TC47`, `TC50`~`TC59` | 텍스트 서식, 회전 동기화, AutoFit 방향A, Spiral 버그 방지, 위/중앙/아래 정렬, 패딩 연동, Ctrl+C/V |
| **`suite-05-bezier.js`** | 베지어 곡선 & 가상 핸들 | `TC30`, `TC31`, `TC33`~`TC37` | 2차/3차 베지어, ESC 취소, S구문 역계산 전파 체인, 5세그먼트 독립성, 베지어 자석선택 |
| **`suite-06-tools.js`** | 캔버스 조작 & 레이어 | `TC10`, `TC12`~`TC14`, `TC16`, `TC18`, `TC21`~`TC23`, `TC32`, `TC48`, `TC49` | 레이어 순서, 클립패스 크롭, 심볼 관리, 정렬/배분, 수치 입력(가로/세로/각도), 90도 회전 |
| **`suite-07-storage.js`** | 슬롯 임시저장 & 복원 | `TC11`, `TC24`, `TC-TEMP-SAVE-01`~`09` | 파일 슬롯 저장/복원, 대용량 JPG 처리, IndexedDB 하이브리드 폴백, 격자 배제 SVG 내보내기 |

## 3. "웹포인터:TC60" 또는 "Webpointer:TC60" 호출 규약
- AI에게 `"웹포인터:TC60 확인해줘"`라고 요청하면:
  - 브라우저 러너 또는 CLI를 통해 즉시 해당 번호의 테스트를 타겟 실행하고 결과를 보고합니다.
