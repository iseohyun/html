사이트 이식판 안내 필터와 리스트 설정은 이 사이트 헤더의 필터 · 설정 아이콘에 있습니다. 견본의 언어 전환은 옮기지 않았고, 전체 설정에 있던 「단어 단축」 켜기 · 끄기는 이 화면의 헤더 설정에 두었습니다.

부분내용동작
요약 줄「총 12건」처럼 건수를 굵게. 필터가 걸려 있으면 그 사실을 옆에 적음.폭이 모자라면 줄바꿈.
보기 전환표 / 카드. 기본은 표.헤더의 설정에서 바꿈. 본문에는 전환 버튼을 두지 않음.
표시 열보일 열을 고름. 이름 열은 항상 보임.헤더의 설정에서 바꿈. 표로 볼 때만 나오는 항목. 숨긴 열로 정렬 중이었다면 기본 정렬로 돌아감.
정렬오래된순 / 최신순.헤더의 설정에서 바꿈. 기간 열을 기준으로 하고 달력과 같은 값을 씀. 그 뒤에 열 머리를 눌러 다른 열로 정렬할 수 있음.
열 머리열 이름과 위아래 화살표 아이콘.누르면 오름차순, 다시 누르면 내림차순. 정렬 중인 열은 화살표가 한 방향으로 바뀜.
행짧은 값은 태그나 배지로, 이름은 굵게, 날짜는 흐리게 한 줄로.호버하면 바탕이 바뀌고, 누르면 상세 창을 엶. 견본에는 상세 창이 없습니다.
카드위에서부터 태그 줄, 제목, 정보 줄, 바닥 줄. 정보 줄은 카드 아래쪽에 붙임.호버하면 3px 떠오르고 테두리가 진해짐.
더 보기목록 아래 가운데 버튼. 남은 건수를 함께 적음.처음에 정해진 수만 그리고, 누를 때마다 같은 수만큼 더 그림. 필터를 바꾸면 처음 수로 돌아감. 남은 것이 없으면 버튼을 숨김.
빈 상태무엇이 없는지와 어떻게 하면 나오는지를 한두 줄로.없음
