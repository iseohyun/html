견본

지도는 두 가지 방식이 있습니다. 경계선만 그려 지역별 건수를 보여 주는 행정구역 보기와, 바깥 지도 서비스 위에 위치를 찍는 지도 API 보기입니다. KoreaEvent는 한 카드 안에서 둘을 오가고, haepungdan은 Google 지도를 씁니다.

견본 · 예시 데이터 · 시도 경계는 KoreaEvent의 자료를 줄인 것 · 지역을 누르면 헤더의 필터와 함께 바뀝니다

행정구역 보기

행정경계 자료만 있으면 그릴 수 있습니다. 바깥 서비스나 키가 필요 없고, 지역별로 얼마나 있는지를 한눈에 보여 줍니다.

  • 자료: 시도 17개와 시군구 250개의 경계를 GeoJSON 파일 두 개로 프로젝트에 둡니다. 구역마다 행정 코드, 이름, 짧은 이름, 중심점, 둘러싼 범위가 들어 있습니다.
  • 그리기: 보여 줄 구역들의 범위를 구해 480×530 그림 영역에 여백 24를 두고 맞춥니다. 가로는 중간 위도의 코사인으로 보정합니다. 경계는 SVG 경로로 바꿉니다.
  • 색: 구역의 건수를 다섯 단계의 진하기로 나타냅니다. 0건이 가장 옅은 단계이고, 나머지 네 단계는 그때그때 가장 많은 구역의 건수를 네 등분해 정합니다. 자료가 적든 많든, 필터를 걸든 항상 차이가 보입니다. 범례에는 단계마다 실제 건수 범위를 적습니다. (KoreaEvent는 1 · 3 · 8 · 15건의 고정 기준을 씁니다.)
  • 세는 범위: 색에 쓰는 건수는 지역 필터를 뺀 나머지 조건으로 셉니다. 지역 하나를 골랐다고 다른 지역이 모두 0건으로 보이지 않게 하기 위해서입니다.
  • 이름표: 구역 중심에 짧은 이름과 건수를 적습니다. 글자 둘레에 표면 색 테두리를 둘러 어떤 색 위에서도 읽히게 합니다.
  • 들어가기: 전체에서 시도를 누르면 그 시도의 시군구 지도로 바뀝니다. 시군구를 누르면 고르고, 다시 누르면 풉니다. 「처음으로」 버튼으로 전체로 돌아옵니다.
  • 움직임 없음: 끌어 옮기거나 확대하지 않습니다. 항상 보여 줄 구역 전체가 화면에 맞게 들어옵니다.

지도 API 보기

실제 위치가 중요할 때 씁니다. 항목마다 위도와 경도가 있어야 하고, 좌표가 없는 항목은 지도에 찍지 않습니다.

부분규칙
바탕 지도지도 서비스의 지도 그림. 출처 표시를 지도 구석에 반드시 남깁니다.
처음 위치전체일 때 남한 전체가 들어오는 중심(북위 36.35, 동경 127.85)과 배율 7. 지역을 골랐으면 그 지역의 중심과 배율.
경계 겹치기행정구역 보기와 같은 경계 자료를 옅게 겹쳐 그립니다. 고른 구역은 선을 굵게, 채움을 진하게. 경계를 눌러 고르는 동작도 행정구역 보기와 같습니다.
범위 맞추기보여 줄 구역이 바뀌면 그 범위가 화면에 들어오게 맞춥니다. 여백 20px.
위치 표시항목마다 반지름 8px 원. 표면 색 2px 테두리. 가리키면 위쪽에 이름과 지역·분류, 누르면 상세.
묶기화면에서 가까이 겹치는 표시가 세 개 이상이면 수를 적은 큰 원 하나로 묶습니다. 묶음을 누르면 그 자리를 확대해 낱개로 풀어 보여 줍니다. 배율이 바뀔 때마다 다시 묶습니다. Leaflet에서는 묶기 플러그인을 씁니다.
옮겨 가기목록에서 항목을 고르면 지도가 그 위치로 미끄러져 갑니다. 이미 화면 안에 있으면 배율을 바꾸지 않습니다. (haepungdan의 방식)
크기 다시 재기보기를 바꾸거나 전체 화면을 오간 직후 지도에 크기가 바뀌었다고 알립니다. 안 그러면 지도 그림이 일부만 나옵니다.
정리화면을 떠날 때 지도 객체를 없앱니다.

기본 화면의 지도 API는 Leaflet + OpenStreetMap입니다. 키와 과금이 없어 어느 프로젝트에나 바로 넣을 수 있습니다. Google 지도는 길 찾기나 장소 정보가 필요한 프로젝트가 고릅니다.

견본의 「지도 API 보기」는 흉내입니다. 미리보기 환경이 바깥의 지도 그림을 불러오지 못하게 막기 때문에, 바탕 지도 없이 경계선 위에 위치 표시만 찍었습니다. 표시의 위치는 실제 좌표가 아니라 지역 중심 둘레에 벌려 놓은 것이고, 묶기도 거리 대신 같은 지역끼리 묶은 것입니다. 묶음을 누르면 확대하는 대신 그 자리에서 풀립니다.
사이트 이식판 안내 이식판의 「지도 API 보기」도 견본과 같은 흉내입니다. 실제 지도 서비스는 붙이지 않았습니다.
