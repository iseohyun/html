# 그림 보기

본문에 작게 넣은 그림(썸네일)을 눌렀을 때 크게 보여 주는 방법입니다. 새 탭이나 새 창으로 내보내지 않고, **그림이 놓여 있던 자리 안에서** 엽니다. 보던 흐름이 끊기지 않게 하기 위해서입니다.

## 구성

```text
ImageViewer                그림이 놓인 영역을 가득 덮음
├─ Stage                   그림 한 장. 비율을 지키며 영역에 맞춤
├─ Foot                    그림 설명 · 「지금 / 전체」
├─ PrevArea                왼쪽 절반. 이전 그림
├─ NextArea                오른쪽 절반. 다음 그림
└─ CloseButton             오른쪽 위 모서리
```

## 여는 자리

| 그림이 있는 곳 | 여는 자리 | 넘기는 범위 |
| :--- | :--- | :--- |
| 슬라이드 안 ([「보고서」 규칙](#/sh-standard/webapp-common-gui/rules/report.md)) | 그 슬라이드를 가득 덮음. 슬라이드 밖의 본문과 화면 틀은 그대로 보임 | 같은 슬라이드의 그림 |
| 슬라이드 밖의 본문 | 창 전체를 덮음 | 같은 페이지(탭)의 슬라이드 밖 그림 |

- 슬라이드를 전체 화면으로 보는 중이면 그림도 전체 화면의 슬라이드 안에서 열립니다.
- 그림의 순서는 문서에 놓인 순서입니다.
- 폭 560px 아래에서 16:9를 푼 슬라이드는 세로로 길어지므로, 이때는 슬라이드 대신 창 전체를 덮습니다.
- 크게 본 화면은 브라우저의 `<dialog>`입니다. 슬라이드 안에서는 그 슬라이드만 덮도록 모달이 아닌 창(`show()`)으로, 창 전체를 덮을 때는 모달(`showModal()`)로 엽니다. 모달은 위층(top layer)에 뜨므로 겹침 순서를 따로 두지 않고, 뒤쪽 화면을 누르거나 읽을 수 없게 막으며, 뒤쪽 화면이 함께 스크롤되지 않게 `overscroll-behavior: contain`을 겁니다.

## 썸네일

| 항목 | 규칙 |
| :--- | :--- |
| 표시 | 가리키면 테두리가 글자색(`--fg`)으로 진해지고 커서는 돋보기 모양(`zoom-in`). |
| 링크 | 썸네일은 큰 그림의 주소를 가진 링크로 만듭니다. 스크립트가 꺼져 있거나 Ctrl·Shift·Cmd와 함께 누르면 브라우저가 그 주소를 그대로 엽니다. |
| 줄의 꼴 | 썸네일 줄(`.thumbs`)은 기본이 2칸입니다. 본문(슬라이드 밖)에 늘어놓을 때는 `.thumbs.is-body`(칸 폭 140 ~ 180px, 간격 12px, 스크립트 폭 안에서 자동 줄바꿈), 슬라이드 폭을 가득 채울 때는 `.thumbs.is-wide`(3칸, 칸의 비율 16:10)를 씁니다. |
| 설명 | 그림마다 한 줄 설명을 붙입니다. 크게 볼 때 아래에 나옵니다. 없으면 대체 글을 씁니다. |
| 바탕 | 흰 종이를 전제로 그린 그림은 테마와 상관없이 흰 바탕에 올립니다. 색 값을 직접 쓰는 유일한 예외입니다. |

## 크게 본 화면

| 부분 | 규칙 |
| :--- | :--- |
| 바탕 | 표면(`--surface`)으로 영역을 완전히 가립니다. 반투명 덮개를 쓰지 않습니다. |
| 그림 | 비율을 지킨 채 남는 자리에 맞춥니다. 자르거나 늘이지 않습니다. |
| 닫기 단추 | 오른쪽 위 모서리, 32px 아이콘 단추, 공통 아이콘의 「닫기」(`i-x`). 슬라이드의 전체 화면 단추와 같은 자리이므로, 그림을 보는 동안에는 전체 화면 단추를 숨깁니다. |
| 설명 줄 | 그림 아래 가운데에 설명과 「지금 / 전체」를 흐린 글씨로. 그림이 한 장이면 쪽 번호는 내지 않습니다. |
| 나타남 | 0.15초(`--t-fast`) 동안 서서히. |

## 넘기기

| 방법 | 규칙 |
| :--- | :--- |
| 마우스 | 화면의 **왼쪽 절반을 누르면 이전 그림, 오른쪽 절반을 누르면 다음 그림**. 절반 전체가 누르는 자리입니다. |
| 안내 표식 | 양쪽 가장자리 가운데에 원형 꺾쇠(`i-chevl`, `i-chevr`)를 흐리게 두고, 그쪽 절반에 마우스가 들어오면 채운 모양으로 진해집니다. |
| 더 갈 곳이 없을 때 | 첫 그림의 왼쪽, 끝 그림의 오른쪽은 표식을 숨기고 눌러도 반응하지 않습니다. 끝에서 처음으로 돌아가지 않습니다. |
| 키보드 | ← 이전, → 다음, Esc 닫기. 보는 동안에는 이 세 키만 받고, 화면 틀의 단축키와 슬라이드 넘기기는 받지 않습니다. |
| 닫을 때 | 눌렀던 썸네일로 초점을 돌려줍니다. 모달은 브라우저가 돌려주고, 슬라이드 안의 창은 초점이 갈 곳을 잃었을 때만 직접 돌려줍니다. 슬라이드를 넘기면 열려 있던 그림도 닫습니다. 모바일의 뒤로 가기 몸짓처럼 브라우저가 창을 닫아도 같은 정리를 합니다. |

## 그 밖의 규칙

| 항목 | 규칙 |
| :--- | :--- |
| 주소 | 그림을 여닫는 것은 주소(`#이름`)를 바꾸지 않습니다. |
| 읽어 주기 | 크게 본 화면은 `<dialog>`라 따로 역할(`role`)을 적지 않아도 대화 상자로 읽히고, `aria-label`로 이름(「그림 크게 보기」)을 갖습니다. 열리면 닫기 단추(`autofocus`)에 초점을 둡니다. |
| 인쇄 | 크게 본 화면은 인쇄하지 않습니다. |

## 아직 확정하지 않은 값

아래는 처음 적용하면서 임시로 정한 것입니다. 써 보고 사용자가 확정합니다.

| 항목 | 임시 결정 |
| :--- | :--- |
| 넘기는 범위 | 슬라이드 안의 그림은 그 슬라이드 안에서만. 슬라이드 밖 그림은 같은 탭 안에서 |
| 끝에서의 동작 | 돌아가지 않고 멈춤 |
| 확대·끌기 | 넣지 않음. 그림을 영역에 맞춰 보여 주기만 함 |
| 손가락으로 밀기 | 넣지 않음. 화면 절반을 눌러 넘김 |
