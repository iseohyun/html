# 새 프로젝트를 시작할 때 쓰는 기본 화면

지금 보고 있는 이 페이지가 기본 화면 그 자체입니다. 위에 고정 헤더, 왼쪽에 아이콘 레일과 펼침 패널이 있고, 본문에는 그 규칙을 적었습니다.

- 헤더의 탭으로 **화면 · 달력 · 리스트 · 지도 · 필터 · 단어 단축 · 구조 · 편의 기능** 을 오갑니다.
- 헤더 오른쪽 아이콘은 차례로 **필터, 페이지 공유, 설정** 입니다. 설정에는 지금 보는 화면에만 해당하는 항목이 나오고, 맨 아래에서 전체 설정으로 갑니다.
- 레일 아래쪽의 두 아이콘은 **로그인** 과 **문서 정보** 페이지를 부릅니다.
- 왼쪽 레일의 두 번째 아이콘은 이 문서용 도구입니다. 영역 경계를 켜거나 모서리 값을 바꿔 볼 수 있습니다.

> 참조 범위: html, KoreaIssue, KoreaEvent에서 컴포넌트 구조와 레이아웃만 가져왔습니다. 색 배치는 가져오지 않았고, 이 페이지의 회색은 자리 표시용입니다.

## 화면 구성

화면은 전체 창을 채우고, 네 영역으로 나뉩니다. 페이지 전체가 아니라 본문 영역만 스크롤합니다.

| 영역 | 크기 | 내용 | 동작 |
| :--- | :--- | :--- | :--- |
| 레일 | 폭 60px | 위쪽 그룹에 주 메뉴 아이콘, 아래쪽 그룹에 로그인과 문서 정보 아이콘. 버튼은 42px 원형. | 넓은 화면에서 항상 보임. 위쪽 아이콘은 패널을 여닫고, 아래쪽 아이콘은 페이지를 부름. |
| 패널 | 폭 240px | 머리(제목, 닫기), 본문(메뉴 목록·검색 등), 하단 블록(버전 등). | 처음에 열려 있음. 열리면 본문을 옆으로 밀어내고, 닫히면 폭 0. |
| 헤더 | 높이 48px | 메뉴 아이콘과 제목, 탭, 시스템 아이콘. 필터 패널이 헤더 아래에 붙어 펼쳐짐. | 항상 위에 고정. 줄바꿈하지 않음. |
| 본문 | 최대 1640px | 페이지 내용. 좌우 여백 최소 16px, 가운데 정렬. 긴 글은 그 안에서 약 52rem 폭으로 제한. | 이 영역만 세로 스크롤. |

## 헤더

한 줄에 세 묶음을 둡니다. 왼쪽과 오른쪽은 세로 가운데, 탭은 바닥에 붙입니다.

```text
[ 메뉴 아이콘 ][ 페이지 제목 ]   ◀── 탭 ──▶   [ 필터 ][ 페이지 공유 ][ 설정 ]
```

| 묶음 | 구성 | 규칙 |
| :--- | :--- | :--- |
| 왼쪽 | 삼단 메뉴 아이콘, 페이지 제목 | 메뉴 아이콘은 넓은 화면에서 패널을 여닫고, 좁은 화면에서 서랍을 엽니다. 제목은 두세 낱말로 짧게 쓰고, 560px 아래에서는 숨깁니다. |
| 가운데 | 탭, 넘칠 때만 양옆의 이동 버튼 | 왼쪽 묶음과 오른쪽 묶음 사이의 남는 폭을 차지하고 가운데 정렬합니다. 제목과 아이콘에 밀려 탭이 다 들어가지 않으면 스크롤바 없이 가로로 밀고, 탭 줄 양옆에 이동 버튼이 생깁니다. 켜진 탭이 보이도록 자동으로 스크롤합니다. |
| 오른쪽 | 시스템 아이콘: 필터, 페이지 공유, 설정 | 32px 정사각 아이콘 버튼. 열려 있는 것은 채운 모양. 필터가 걸려 있으면 필터 아이콘에 점을 찍습니다. 공유는 현재 주소를 복사하고 짧은 알림을 띄웁니다. |

### 탭 모양

| 항목 | 값 |
| :--- | :--- |
| 모양 | 윗변이 좁은 사다리꼴. `clip-path: polygon(9px 0, calc(100% - 9px) 0, 100% 100%, 0 100%)` |
| 위치 | 헤더 바닥에 붙음. 헤더 아래 경계선을 1px 덮어서 활성 탭이 본문과 이어져 보이게 합니다. |
| 활성 탭 | 배경이 아래 문서 배경(`--bg`)과 같은 색. 위아래 안쪽 여백을 3px 늘려 조금 더 높게. |
| 비활성 탭 | 음영(`--active`)에 흐린 글자. 헤더 바탕(`--sunken`)보다 한 단계 진하게. |
| 글씨 | 본문 크기의 80%, 굵게, 한 줄. |
| 간격 | 탭 사이 3px, 안쪽 여백 7px 20px 6px. |
| 글자색 | 방문 여부와 상관없이 같습니다. 꺼진 탭은 `--muted`, 켜진 탭은 `--fg`. 탭을 링크(`<a>`)로 만들 때는 `:visited` 색이 섞이지 않게 합니다. |
| 넘칠 때 | 탭이 넘쳐 가로로 밀릴 때, 켜진 탭이 보이도록 탭 줄의 가운데로 자동 스크롤합니다. 창 크기가 바뀔 때도 다시 맞춥니다. |

### 탭이 다 들어가지 않을 때

| 항목 | 규칙 |
| :--- | :--- |
| 이동 버튼 | 탭 줄의 왼쪽 끝과 오른쪽 끝에 하나씩. 탭이 다 들어갈 때는 없고, 넘칠 때만 둘이 함께 나타납니다. 폭 22px, 꺾쇠 아이콘 16px, 탭과 같은 바닥에 맞춥니다. |
| 더 갈 곳이 없을 때 | 그쪽 버튼을 흐리게 하고 잠급니다. 버튼을 없애지 않는 것은 탭 줄의 폭이 출렁이지 않게 하기 위해서입니다. |
| 한 번에 가는 거리 | 보이는 탭 줄 폭의 60%. 부드럽게 밉니다. |
| 끌어서 밀기 | 탭 줄을 잡고 좌우로 끌면 따라 움직입니다. 넘칠 때는 손 모양 커서로 알립니다. 5px 넘게 끌었으면 손을 뗄 때 탭을 고른 것으로 치지 않습니다. |
| 손가락으로 밀기 | 터치 기기에서는 브라우저의 가로 밀기를 그대로 씁니다. |
| 켜진 탭 보이기 | 탭이 바뀌거나 창 크기가 바뀌면, 켜진 탭이 탭 줄의 가운데에 오도록 자동으로 스크롤합니다. |
| 다시 재는 때 | 창 크기가 바뀔 때, 사이드바를 여닫을 때, 언어를 바꿔 탭 글자가 달라질 때. |

> 공유 버튼은 현재 주소를 복사합니다. 이 견본은 미리보기 프레임 안에서 돌기 때문에 프레임의 주소가 복사됩니다.

## 설정

설정은 두 층으로 나눕니다. 헤더의 톱니 아이콘은 **지금 보는 화면에만 해당하는 항목** 을 필터와 같은 자리, 같은 모양으로 펼칩니다. 어느 화면에서나 같은 설정은 **전체 설정** 페이지에 모으고, 화면별 설정의 맨 아래 줄에서 링크로 들어갑니다.

| 보는 화면 | 톱니 아이콘에 나오는 항목 |
| :--- | :--- |
| 달력 | 달력 칸(자동 / 칩 / 점), 칩 내용(지역 · 분류), 기간 항목(날마다 반복 / 가로 막대), 이어보기, 빈 주 생략, 정렬(오래된순 / 최신순) |
| 리스트 | 리스트 보기(표 / 카드), 정렬(오래된순 / 최신순) |
| 리스트가 표일 때만 | 표시 열 |
| 지도 | 지도 방식(행정구역 보기 / 지도 API 보기), 범례 |
| 그 밖의 화면 | 「이 화면에만 해당하는 설정은 없습니다」 한 줄 |
| 모든 화면의 맨 아래 줄 | 전체 설정으로 가는 링크 |

| 층 | 자리 | 담는 것 |
| :--- | :--- | :--- |
| 화면별 설정 | 헤더 아래로 펼쳐지는 패널 | 위 표의 항목 |
| 전체 설정 | 별도 페이지. 헤더 탭에는 올리지 않음 | 언어, 테마, 글자 크기, 단어 단축, 되돌리기 |
| 단축키 | 전체 설정에서 한 번 더 들어가는 하위 페이지 | 단축키 목록, 바꾸기, 단축키 기본값 |

| 부분 | 치수 | 모양 |
| :--- | :--- | :--- |
| 패널 | 본문과 같은 최대 폭, 최대 높이 화면의 70% | 필터 패널과 같은 컴포넌트. 넘치면 패널 안에서 세로 스크롤. |
| 항목 줄 | 76px + 나머지, 사이 12px | 왼쪽에 0.8rem 굵은 항목 이름, 오른쪽에 버튼을 가로로 나열하고 넘치면 줄바꿈. 줄 사이는 점선. 전체 설정과 단축키 페이지도 같은 줄을 카드 안에 씁니다. |
| 필터와의 관계 |  | 같은 자리에 펼쳐지므로 한 번에 하나만 엽니다. |
| 닫기 |  | 톱니 아이콘을 다시 누르거나 Esc. 전체 설정 링크를 누르면 닫히면서 이동합니다. |

### 기억하기

| 무엇을 | 어디에 | 규칙 |
| :--- | :--- | :--- |
| 설정 값 전체 | localStorage | 값이 바뀔 때마다 저장. 키 이름은 `프로젝트_settings_v1`처럼 끝에 판 번호를 붙이고, 모양이 바뀌면 번호를 올립니다. |
| 사이드바 상태 | localStorage | 패널이 열려 있었는지와 마지막에 본 탭. |
| 읽을 때 |  | 항목마다 허용된 값인지 확인하고, 어긋난 항목만 기본값으로 둡니다. 읽기나 쓰기에 실패해도 화면은 기본값으로 정상 동작하고 경고만 남깁니다. |
| 스크롤 위치 | 메모리 | 탭을 떠날 때 위치를 적어 두고 돌아오면 되돌립니다. 달력 안쪽 스크롤도 같이 기억합니다. |
| 필터 값 | 주소 | 브라우저에 저장하지 않고 주소에 담습니다. |

> 견본의 영어는 화면 글자 일부만 바뀝니다. 미리보기 환경에 따라 저장이 막혀 있으면 설정은 새로 고칠 때 처음 값으로 돌아갑니다.

## 단축키

자주 쓰는 동작에 한 글자 단축키를 붙입니다. **Alt** 를 누르고 있는 동안 해당 버튼 모서리에 단축키 배지가 나타납니다.

| 동작 | 기본 키 | 배지가 붙는 곳 |
| :--- | :--- | :--- |
| 목차 · 미리보기 설정 · 문서 정보 | 1 · 2 · 3 | 레일 아이콘 |
| 사이드바 여닫기 | M | 헤더 메뉴 아이콘 |
| 필터 여닫기 | F | 헤더 필터 아이콘 |
| 검색 칸으로 (필터를 열고 커서를 둠) | / | 없음 |
| 화면별 설정 여닫기 | , | 헤더 설정 아이콘 |
| 이전 탭 · 다음 탭 | [ · ] | 없음 |
| 열린 창과 서랍 닫기 | Esc | 없음 (바꿀 수 없음) |

- 입력 칸에 글자를 넣는 중에는 단축키가 동작하지 않습니다. Ctrl, Alt, Cmd와 함께 누른 키도 건드리지 않아 브라우저 단축키와 부딪히지 않습니다.
- **바꾸기**: 전체 설정에서 한 번 더 들어가는 단축키 페이지에서, 키가 적힌 버튼을 누르고 새 키를 누릅니다. 이미 쓰는 키는 받지 않고 어디서 쓰는지 알려 줍니다. Esc로 취소합니다.
- 바꾼 단축키는 설정과 별도 키로 브라우저에 기억하고, 「단축키 기본값」으로 되돌립니다.
- 배지는 16px 네모에 고정폭 글자, 버튼 오른쪽 아래 모서리에 겹쳐 놓습니다.

## 문서 정보와 로그인

레일 아래쪽 그룹의 두 아이콘은 패널을 여는 대신 **페이지를 부릅니다**. 본문 전체를 쓰고, 그동안 사이드바는 그 페이지의 목차를 보여 줍니다.

| 아이콘 | 부르는 페이지 | 내용 |
| :--- | :--- | :--- |
| 사람 | 로그인 | 제공자별 로그인 버튼. 기본으로 Google을 지원합니다. 규칙은 로그인 페이지에 적었습니다. |
| 정보 | 문서 정보 | 이 문서 소개와 버전, 변경 이력, 의견 보내기. |

| 문서 정보의 묶음 | 내용 | 규칙 |
| :--- | :--- | :--- |
| 이 문서 | 정식 버전, 빌드 표시(`YYYYMMDDvN`), 참조, 자료 출처. | 정식 버전은 사용자가 승인할 때만 올리고, 빌드 표시는 빌드할 때마다 자동으로 바꿉니다. |
| 변경 이력 | 최근 판부터 아래로. 판 번호, 날짜, 바뀐 내용. | 바뀐 내용 앞에 「추가 / 바꿈 / 고침 / 삭제」 태그. 자료는 `changelog.json` 한 파일로 관리합니다. |
| 의견 보내기 | 내용(필수), 답장 주소(선택), 보내기 버튼, 결과 한 줄. | 아래 표 참고. |

### 의견 보내기와 Web3Forms

| 항목 | 규칙 |
| :--- | :--- |
| 발송 | 서버를 두지 않고 화면에서 바로 Web3Forms로 보냅니다. `https://api.web3forms.com/submit`에 JSON을 POST합니다. |
| 보내는 값 | `access_key`, `subject`(프로젝트 이름 포함), `message`, `email`(있을 때만), 지금 보던 페이지 이름과 버전. |
| 접근 키 | 받는 주소에 묶인 공개용 키라 화면 코드에 둘 수 있습니다. 그래도 값은 설정 파일 한 곳에 모읍니다. |
| 자동 입력 막기 | 사람 눈에 안 보이는 체크 칸(`botcheck`)을 두고, 채워져 있으면 보내지 않습니다. |
| 확인 | 내용은 다섯 글자 이상. 주소는 비워도 되고, 적었다면 모양을 확인합니다. |
| 결과 | 보내는 동안 버튼을 잠그고, 성공하면 칸을 비우고 「보냈습니다」, 실패하면 내용을 남긴 채 이유와 다시 시도 안내를 보여 줍니다. |

> 이 견본은 미리보기 환경이 바깥 주소로의 전송을 막고 있어 의견을 실제로 보내지 않고, 로그인도 하지 않습니다. Web3Forms의 주소와 필드 이름은 구현할 때 공식 문서로 다시 확인해야 합니다.

| 기능 | 규칙 |
| :--- | :--- |
| 오류 경계 | 앱 전체를 오류 경계로 감쌉니다. 화면을 그리다 오류가 나면 하얀 화면 대신 「문제가 생겼습니다」, 오류 한 줄, 「다시 시도」와 「새로 고침」 버튼을 보여 줍니다. |
| 경계의 단위 | 본문 영역에 하나를 더 둡니다. 본문이 깨져도 헤더와 사이드바는 살아 있어 다른 페이지로 옮길 수 있습니다. |
| 빈 처리 금지 | 오류를 조용히 삼키지 않습니다. 무시해도 되는 오류라도 콘솔에 이유를 남깁니다. |
| 버전 두 가지 | 정식 버전(`v0.4.0`)과 빌드 표시(`20261113v1`)를 한 파일에서 관리합니다. |
| 캐시 갱신 | 빌드 표시를 스크립트와 스타일 파일 이름이나 `?v=`에 붙여, 배포하면 강제 새로 고침 없이 새 파일을 받게 합니다. |
| 새 판 알림 | 앱을 연 직후, 다른 앱에서 돌아와 화면이 다시 보일 때, 그리고 30분마다 서버의 `index.html`을 캐시 없이 받아 빌드 표시를 비교합니다. 다르면 화면 아래 가운데에 「새 버전이 있습니다」와 「새로 고침」·닫기 버튼을 띄웁니다. 저절로 다시 불러오지 않습니다. 닫은 판은 다시 알리지 않고, 그 뒤의 새 판은 다시 알립니다. 설치한 앱은 닫았다 열어도 다시 불러오지 않고 새로 고침 버튼도 없어서, 이것이 새 판을 받는 유일한 길입니다. |
| 표시 자리 | 패널 하단 블록과 문서 정보. |

## 컴포넌트 구조

```text
AppShell
├─ Sidebar
│  ├─ SidebarRail      아이콘 띠 (위 그룹 / 아래 그룹)
│  └─ SidebarPanel     펼침 패널 (머리 / 본문 / 하단 블록)
├─ Backdrop            좁은 화면에서 서랍 뒤를 덮음
├─ HeaderBar
│  ├─ 왼쪽             메뉴 아이콘 · 페이지 제목
│  ├─ PageTabs         사다리꼴 탭
│  ├─ 오른쪽           필터 · 페이지 공유 · 설정
│  ├─ FilterPanel      헤더 아래로 펼쳐짐
│  └─ SettingsPanel    같은 자리에 펼쳐지는 화면별 설정
└─ Main                본문 (최대 폭, 가운데 정렬)
   ├─ 탭 페이지        화면 · 달력 · 리스트 · 필터 …
   └─ 보조 페이지      전체 설정 › 단축키, 문서 정보, 로그인
```

| 상태 | 값 | 누가 바꾸나 |
| :--- | :--- | :--- |
| 열린 패널 | 탭 이름 또는 없음 | 레일 아이콘, 헤더 메뉴 아이콘, 패널 닫기 버튼 |
| 서랍 열림 | 참 / 거짓 | 헤더 메뉴 아이콘, 덮개 클릭, Esc 키, 메뉴 항목 선택 |
| 현재 페이지 | 페이지 이름 | 헤더 탭. 주소의 `#이름`과 맞춤 |
| 필터 열림 · 필터 값 | 참 / 거짓 · 항목별 값 | 헤더 필터 아이콘, 필터 패널의 컨트롤 |
| 설정 값 | 항목별 값 | 설정 창의 컨트롤 |

기술 구성은 고정하지 않습니다. 순수 HTML이든 React든 위 구조와 이름만 맞춥니다. 계산이 무거워졌을 때 화면과 계산을 어떻게 나누는지는 구조 탭에 적었습니다.

## 좁은 화면

기준은 960px 하나입니다. 그 아래에서는 레일과 패널을 한 덩어리 서랍으로 묶어 숨깁니다.

|  | 961px 이상 | 960px 이하 |
| :--- | :--- | :--- |
| 레일 | 항상 보임 | 서랍 안에만 있음 |
| 패널 | 열리면 본문을 밀어냄 | 서랍 안에서 항상 펼쳐져 있음 |
| 메뉴 아이콘 | 패널을 여닫음 | 서랍을 엶 |
| 덮개 | 없음 | 서랍이 열리면 나머지 화면을 어둡게 덮고, 누르면 서랍을 닫음 |
| 탭 | 가운데 정렬. 넘치면 양옆에 이동 버튼 | 왼쪽 정렬. 넘치면 양옆에 이동 버튼이 생기고 손가락으로도 밀며, 켜진 탭이 보이게 자동 스크롤 |

## 스타일 규칙

### 선형 아이콘

면을 채우지 않은 선 아이콘만 씁니다. 24px 격자에 선 굵기 1.75px, 끝과 모서리는 둥글게 처리합니다. 레일에서는 24px, 그 밖의 버튼에서는 20px, 글자 옆에서는 14px로 씁니다.

### 공통 아이콘

기능마다 아이콘을 하나로 정해 둡니다. 어느 프로젝트에서나 같은 기능은 같은 그림입니다.

- 한 기능에 아이콘 하나, 한 아이콘에 뜻 하나. 같은 그림을 두 가지 뜻으로 쓰지 않습니다. 「위치」와 「고정하기」처럼 헷갈리기 쉬운 것은 그림을 나눴습니다.
- 아이콘만 있는 버튼에는 읽어 주는 이름과 가리켰을 때 뜨는 이름을 반드시 붙입니다.
- 켜고 끄는 짝은 그림을 바꿉니다. 보이기와 숨기기, 스피커와 음소거, 오름차순과 내림차순.
- 아래 「이름」은 Lucide 아이콘 묶음의 이름입니다. 다른 묶음을 쓰는 프로젝트는 같은 뜻의 그림으로 맞춥니다.

> 이 표에 없는 기능이 생기면 먼저 여기에 더한 다음 씁니다. 견본의 그림은 Lucide를 따라 손으로 그린 것이라 원본과 조금 다를 수 있습니다.

### 둥근 모서리

세 단계와 알약형만 씁니다. 레일의 「미리보기 설정」에서 값을 바꾸면 아래 견본도 함께 바뀝니다.

### 짧은 전환효과

전환은 0.15초에서 0.5초 사이로, 움직임이 클수록 길게 잡습니다. 가속 곡선은 `ease` 하나만 씁니다. 운영체제에서 동작 줄이기를 켠 사용자에게는 전환을 끕니다.

### 스크롤바

스크롤바는 눈에 띄지 않게 가는 막대만 남깁니다. 이 페이지의 본문, 사이드바 패널, 달력 안쪽이 모두 이 모양입니다.

| 부분 | 치수 | 모양 |
| :--- | :--- | :--- |
| 바탕 |  | 투명. 스크롤되는 영역의 배경이 그대로 비쳐서 문서의 배경과 같아 보입니다. 따로 색을 칠하지 않습니다. |
| 위아래 단추 | 없음 | 화살표 단추를 없앱니다. |
| 막대 | 자리 8px, 보이는 굵기 4px | `--line` 색, 양 끝이 둥근 알약형. 자리의 양옆 2px는 비워 둡니다. |
| 가리킨 막대 |  | `--muted` 색으로 진해집니다. |
| 가로 스크롤바 | 같은 치수 | 표와 코드 상자에 같은 모양으로 나옵니다. 헤더의 탭 줄처럼 좁은 띠에서는 아예 숨깁니다. |
| 브라우저 차이 |  | 크롬·엣지·사파리는 위 치수 그대로, 파이어폭스는 브라우저의 「가늘게」 모양에 같은 색을 씁니다. 손가락으로 미는 기기는 원래 스크롤바가 겹쳐 뜨므로 그대로 둡니다. |

## 색과 테마

기본 화면은 강조색을 정하지 않습니다. 대신 중립적인 테마 네 가지(밝게, 어둡게, 스톤, 네이비)를 기본으로 제공하고, 사용자가 설정에서 고릅니다. 프로젝트는 여기에 자기 강조색과 글꼴을 얹습니다.

- 테마는 아래 역할 토큰의 값만 바꿉니다. 컴포넌트 쪽 스타일은 테마를 몰라도 됩니다.
- 스톤은 색상을 쓰지 않는 돌빛 회색입니다. 달력의 일요일과 토요일도 회색의 진하기로만 구분합니다.
- 선택된 항목은 색이 아니라 **면과 굵기** 로 표시합니다. 메뉴는 옅은 면에 굵은 글씨, 켜진 버튼은 글자색으로 채운 면입니다.
- 컴포넌트는 색 값을 직접 쓰지 않고 역할 이름만 씁니다.
- 이 페이지는 보는 사람의 시스템 설정을 따라 밝게 또는 어둡게 보입니다.

| 역할 | 토큰 | 쓰이는 곳 |
| :--- | :--- | :--- |
| 바탕 | --bg | 본문 배경, 활성 탭, 필터 패널 |
| 표면 | --surface | 버튼, 표, 카드, 달력, 설정 창 |
| 가라앉은 면 | --sunken | 헤더, 레일, 패널, 표 머리 |
| 선 | --line | 영역 경계, 테두리 |
| 글자 | --fg | 본문 글자, 켜진 버튼의 면 |
| 흐린 글자 | --muted | 보조 설명, 꺼진 항목 |
| 선택·호버 면 | --active | 선택된 메뉴, 호버, 비활성 탭, 달력 막대 |
| 일요일·공휴일 | --day-sun | 달력의 날짜 숫자와 공휴일 이름. 기본값 빨강. |
| 토요일 | --day-sat | 달력의 날짜 숫자. 기본값 파랑. |
| 알림 | --alert | 필터 적용 표시 점. 기본값 빨강. |
