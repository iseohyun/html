# 로그인

레일 아래쪽의 사람 아이콘이 이 페이지를 부릅니다. 기본으로 Google 계정을 지원합니다.

## 규칙

| 항목 | 규칙 |
| :--- | :--- |
| 들어가는 길 | 레일 아래쪽 그룹의 사람 아이콘. 로그인이 필요한 동작을 눌렀을 때도 이 페이지를 부릅니다. |
| 페이지로 부르기 | 헤더나 패널 안의 작은 창이 아니라 본문 전체를 쓰는 페이지입니다. 헤더와 사이드바는 그대로 남습니다. |
| 기본 제공자 | Google. 팝업으로 열고, 팝업이 막힌 환경에서는 화면 이동 방식으로 바꿉니다. |
| 제공자 추가 | 버튼을 세로로 한 줄씩 더합니다. 순서는 Google이 맨 위. |
| 로그인한 뒤 | 로그인 직전에 보던 화면과 필터로 돌아갑니다. |
| 로그인 상태 표시 | 레일의 사람 아이콘이 이름 첫 글자로 바뀌고, 누르면 이 페이지에서 계정 이름과 로그아웃 버튼을 보여 줍니다. |
| 실패했을 때 | 버튼 아래에 이유 한 줄과 다시 시도 안내. 사용자가 창을 닫은 경우에는 아무 말도 하지 않습니다. |
| 기억 | 로그인 상태는 인증 서비스가 맡습니다. 화면 쪽은 어느 제공자로 로그인했는지만 기억해 다음에 그 버튼을 먼저 보여 줍니다. |

> 참조: KoreaEvent는 헤더의 작은 창에서, CharQuiz는 별도 로그인 화면에서, haepungdan과 html은 Firebase 인증으로 Google 로그인을 합니다. 이 견본은 실제로 로그인하지 않습니다.
