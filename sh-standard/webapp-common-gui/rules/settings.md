# 전체 설정

어느 화면에서나 똑같이 적용되는 설정입니다. 헤더의 톱니 아이콘에는 지금 보는 화면에만 해당하는 항목만 있고, 그 맨 아래 링크로 여기에 옵니다.

## 설정의 두 층

| 층 | 들어가는 길 | 담는 것 |
| :--- | :--- | :--- |
| 화면별 설정 | 헤더의 톱니 아이콘 | 지금 보는 화면에만 해당하는 항목. 달력이면 달력 칸·기간 항목·이어보기·빈 주 생략·정렬, 리스트면 보기 방식·정렬, 표일 때만 표시 열. 맨 아래에 전체 설정 링크. |
| 전체 설정 | 화면별 설정 맨 아래의 링크 | 언어, 테마, 팔레트 색, 글자 크기, 단어 단축, 되돌리기. 별도 페이지. |
| 단축키 | 전체 설정 안의 링크 | 단축키 목록과 바꾸기. 전체 설정에서 한 번 더 들어가는 하위 페이지. |

- 화면별 설정에 해당 항목이 없는 화면에서는 안내 한 줄과 전체 설정 링크만 보여 줍니다.
- 전체 설정과 단축키는 헤더 탭에 올리지 않습니다. 링크로만 들어가고, 사이드바는 그 페이지의 목차를 보여 줍니다.
- 세 층 모두 같은 줄 모양을 씁니다. 왼쪽에 항목 이름, 오른쪽에 내용입니다.
