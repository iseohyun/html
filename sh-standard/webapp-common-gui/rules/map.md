# 지도

지도는 두 가지 방식이 있습니다. 경계선만 그려 지역별 건수를 보여 주는 **행정구역 보기** 와, 바깥 지도 서비스 위에 위치를 찍는 **지도 API 보기** 입니다. KoreaEvent는 한 카드 안에서 둘을 오가고, haepungdan은 Google 지도를 씁니다.

## 공통 구성

```text
MapView
└─ MapCard                보통 크기 / 전체 화면
   └─ MapBody
      ├─ RemoteControl    오른쪽 위, 아이콘만 세로로
      │  ├─ 전체 화면
      │  ├─ 행정구역 보기 · 지도 API 보기   (둘 중 하나)
      │  └─ 범례 · 처음으로
      ├─ 지도 본체        SVG 경계 지도 또는 지도 API 영역
      ├─ HoverTooltip     왼쪽 아래, 가리킨 곳의 이름과 건수
      └─ Legend           오른쪽 아래, 끌 수 있음
```

| 부분 | 치수 | 모양과 동작 |
| :--- | :--- | :--- |
| 지도 카드 | 본체 높이 550px | 표면 색, 1px 테두리, `--r-lg`. 지도 본체는 바탕 색. |
| 조작 묶음 | 버튼 36px, 사이 4px, 오른쪽 위 12px | 표면 색 카드에 아이콘 버튼을 세로로. 묶음 사이는 가는 선. 켜진 버튼은 채운 면. |
| 전체 화면 | 화면 전체 | 카드를 화면 전체로 넓힘. Esc나 같은 버튼으로 돌아옴. 지도 API 보기는 크기가 바뀐 뒤 지도에 크기를 다시 재라고 알려야 함. |
| 가리킴 안내 | 왼쪽 아래 12px | 글자색 면에 바탕색 글자. 지역 이름과 건수, 또는 항목 이름. |
| 범례 | 오른쪽 아래 12px | 색 단계와 건수 범위. 조작 묶음의 버튼으로 켜고 끔. |
| 필터와의 관계 |  | 지도에서 고른 지역은 헤더 필터의 지역과 같은 값. 지도에서 누르면 필터가 바뀌고, 필터에서 바꾸면 지도의 선택 표시가 따라옴. |

## 행정구역 보기

행정경계 자료만 있으면 그릴 수 있습니다. 바깥 서비스나 키가 필요 없고, 지역별로 얼마나 있는지를 한눈에 보여 줍니다.

- **자료**: 시도 17개와 시군구 250개의 경계를 GeoJSON 파일 두 개로 프로젝트에 둡니다. 구역마다 행정 코드, 이름, 짧은 이름, 중심점, 둘러싼 범위가 들어 있습니다.
- **그리기**: 보여 줄 구역들의 범위를 구해 480×530 그림 영역에 여백 24를 두고 맞춥니다. 가로는 중간 위도의 코사인으로 보정합니다. 경계는 SVG 경로로 바꿉니다.
- **색**: 구역의 건수를 다섯 단계의 진하기로 나타냅니다. 0건이 가장 옅은 단계이고, 나머지 네 단계는 그때그때 가장 많은 구역의 건수를 네 등분해 정합니다. 자료가 적든 많든, 필터를 걸든 항상 차이가 보입니다. 범례에는 단계마다 실제 건수 범위를 적습니다. (KoreaEvent는 1 · 3 · 8 · 15건의 고정 기준을 씁니다.)
- **세는 범위**: 색에 쓰는 건수는 지역 필터를 뺀 나머지 조건으로 셉니다. 지역 하나를 골랐다고 다른 지역이 모두 0건으로 보이지 않게 하기 위해서입니다.
- **이름표**: 구역 중심에 짧은 이름과 건수를 적습니다. 글자 둘레에 표면 색 테두리를 둘러 어떤 색 위에서도 읽히게 합니다.
- **들어가기**: 전체에서 시도를 누르면 그 시도의 시군구 지도로 바뀝니다. 시군구를 누르면 고르고, 다시 누르면 풉니다. 「처음으로」 버튼으로 전체로 돌아옵니다.
- **움직임 없음**: 끌어 옮기거나 확대하지 않습니다. 항상 보여 줄 구역 전체가 화면에 맞게 들어옵니다.

| 부분 | 치수 | 모양 |
| :--- | :--- | :--- |
| 구역 | 경계선 1.2px | 경계선은 표면 색. 채움은 건수 단계에 따른 진하기. |
| 가리킨 구역 | 경계선 2px | 경계선이 글자색으로. |
| 고른 구역 | 경계선 2.6px | 글자색 굵은 경계선. |
| 이름표 | 10.5px, 건수 9px | 굵게, 가운데 정렬, 표면 색 3px 테두리. 누르는 데 방해되지 않게 클릭을 통과시킴. |

> 견본은 시도 단계만 있고 시군구로 들어가지 않습니다. 대신 시도를 누르면 그 지역이 필터에 걸립니다. 경계는 점을 약 8분의 1로 솎고 작은 섬을 뺀 것이라 실제보다 거칩니다.

## 지도 API 보기

실제 위치가 중요할 때 씁니다. 항목마다 위도와 경도가 있어야 하고, 좌표가 없는 항목은 지도에 찍지 않습니다.

| 부분 | 규칙 |
| :--- | :--- |
| 바탕 지도 | 지도 서비스의 지도 그림. 출처 표시를 지도 구석에 반드시 남깁니다. |
| 처음 위치 | 전체일 때 남한 전체가 들어오는 중심(북위 36.35, 동경 127.85)과 배율 7. 지역을 골랐으면 그 지역의 중심과 배율. |
| 경계 겹치기 | 행정구역 보기와 같은 경계 자료를 옅게 겹쳐 그립니다. 고른 구역은 선을 굵게, 채움을 진하게. 경계를 눌러 고르는 동작도 행정구역 보기와 같습니다. |
| 범위 맞추기 | 보여 줄 구역이 바뀌면 그 범위가 화면에 들어오게 맞춥니다. 여백 20px. |
| 위치 표시 | 항목마다 반지름 8px 원. 표면 색 2px 테두리. 가리키면 위쪽에 이름과 지역·분류, 누르면 상세. |
| 묶기 | 화면에서 가까이 겹치는 표시가 세 개 이상이면 수를 적은 큰 원 하나로 묶습니다. 묶음을 누르면 그 자리를 확대해 낱개로 풀어 보여 줍니다. 배율이 바뀔 때마다 다시 묶습니다. Leaflet에서는 묶기 플러그인을 씁니다. |
| 옮겨 가기 | 목록에서 항목을 고르면 지도가 그 위치로 미끄러져 갑니다. 이미 화면 안에 있으면 배율을 바꾸지 않습니다. (haepungdan의 방식) |
| 크기 다시 재기 | 보기를 바꾸거나 전체 화면을 오간 직후 지도에 크기가 바뀌었다고 알립니다. 안 그러면 지도 그림이 일부만 나옵니다. |
| 정리 | 화면을 떠날 때 지도 객체를 없앱니다. |

### 어떤 지도 서비스를 쓸까

|  | 행정구역 보기 | Leaflet + OpenStreetMap | Google 지도 |
| :--- | :--- | :--- | :--- |
| 쓰는 곳 | KoreaEvent | KoreaEvent | haepungdan |
| 키 | 필요 없음 | 필요 없음 | 필요함 |
| 비용 | 없음 | 없음 (사용량이 많으면 지도 그림을 따로 구해야 함) | 사용량에 따라 과금 |
| 필요한 것 | 경계 자료 파일 | Leaflet 라이브러리 | Google 지도 라이브러리, 지도 ID |
| 확대와 이동 | 없음 | 있음 | 있음 |
| 정확한 위치 | 구역 단위까지 | 좌표 그대로 | 좌표 그대로 |
| 잘 맞는 일 | 지역별 분포, 지역 고르기 | 위치 확인, 가벼운 지도 | 길 찾기 연결, 장소 정보, 위성 사진 |

기본 화면의 지도 API는 Leaflet + OpenStreetMap입니다. 키와 과금이 없어 어느 프로젝트에나 바로 넣을 수 있습니다. Google 지도는 길 찾기나 장소 정보가 필요한 프로젝트가 고릅니다.

> 견본의 「지도 API 보기」는 흉내입니다. 미리보기 환경이 바깥의 지도 그림을 불러오지 못하게 막기 때문에, 바탕 지도 없이 경계선 위에 위치 표시만 찍었습니다. 표시의 위치는 실제 좌표가 아니라 지역 중심 둘레에 벌려 놓은 것이고, 묶기도 거리 대신 같은 지역끼리 묶은 것입니다. 묶음을 누르면 확대하는 대신 그 자리에서 풀립니다.

## 확정한 값

| 항목 | 결정 |
| :--- | :--- |
| 기본 지도 API | Leaflet + OpenStreetMap. Google 지도는 필요한 프로젝트가 고름 |
| 지도와 필터 | 연동. 지도에서 고른 지역이 곧 헤더 필터의 지역 |
| 색 단계 | 그때그때 가장 많은 지역을 최대로 놓고 나눔. 0건은 따로 한 단계 |
| 위치 표시가 많을 때 | 가까운 표시를 하나로 묶어 수를 적음 |
| 지도의 자리 | 헤더 탭 |
