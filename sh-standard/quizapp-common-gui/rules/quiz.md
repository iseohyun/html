# 문제 화면

문제 하나에 보기 네 개를 보여 주고, 응답 속도와 정오로 항목의 단계를 올리고 내립니다. 엔진은 `components/engine.js` 하나에 있고 두 앱이 같은 구조입니다.

## 단계와 복습 때

항목마다 단계(stage) 0~8을 둡니다. 0은 아직 해금되지 않은 항목입니다.

| 단계 | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| 복습 간격 | 1분 | 10분 | 30분 | 2시간 | 1일 | 3일 | 7일 | 15일 | 30일 |

- `INTERVALS = [1, 10, 30, 120, 1440, 4320, 10080, 21600, 43200]`(분).
- **복습 때**: 한 번이라도 풀었고(`totalSolved > 0`), 마지막으로 푼 뒤 그 단계의 간격이 지났을 때.

## 출제 풀

학습 모드를 시작할 때 풀(기본 10개)을 다음 순서로 채웁니다.

1. 복습 때가 된 항목. 단계가 낮은 순, 같으면 평균 응답이 느린 순. 이 항목만 이번 판에서 **승급 자격**을 얻습니다.
2. 자리가 남으면 기록은 있지만 평균 응답이 느린 항목(CharQuiz 1200ms, NameQuiz 1500ms 넘음)을 느린 순으로. 일찍 불러 연습시키되 승급 자격은 없습니다.
3. 자동 진도가 켜져 있고 자리가 남으면 아직 배우지 않은 항목 **1개**(데이터 순서의 첫 번째).
4. 그래도 4개가 안 되면 기록 있는 항목(느린 순), 그다음 아무 항목으로 4개를 채웁니다.

### 복습은 항상 포함

범위가 묶음(언어)으로 나뉜 앱에서는, 요약 카드에서 **꺼 둔 같은 묶음의 범위라도 복습할 때가 된 항목은 학습에 함께 냅니다**(CharQuiz). 복습을 미루면 간격 반복이 무너지기 때문입니다.

1. 켜 둔 범위마다 위 1~4단계로 풀을 만듭니다.
2. 같은 묶음에서 꺼 둔 범위마다 복습 때가 된 항목(승급 자격이 있는 항목)만 더합니다. **새 항목은 켜 둔 범위에서만** 냅니다.
3. 풀이 설정의 문제 수(최소 4)를 넘으면 섞은 뒤 **복습 항목을 먼저 남기고** 자릅니다.

- 헤더의 복습 대기 수 배지도 같은 기준으로 묶음 전체를 셉니다.
- 다른 묶음(언어)의 복습 항목은 넣지 않습니다.

- 문제는 풀에서 고르되 직전 문제와 같은 항목은 피합니다(NameQuiz 방식. CharQuiz 학습 모드는 연속을 허용).

## 보기 네 개와 같은 발음 막기

정답과 **소리나 이름이 같은 오답**이 보기에 섞이면 맞혀도 틀려도 의미가 없습니다. 보기마다 「비교 열쇠」를 만들어 열쇠가 겹치는 항목은 오답으로 쓰지 않습니다.

| 앱 | 비교 열쇠 |
| :--- | :--- |
| CharQuiz | `getSoundKey`: 가타카나를 히라가나로 바꾸고(U+30A1~30F6에서 0x60을 뺌), `ぢ→じ`, `づ→ず`, `を→お`로 모으고, 소문자로 바꿉니다(A와 a는 같은 소리). |
| NameQuiz | 한글 이름(`koName`). 시즌마다 같은 이름의 캐릭터가 있어도 보기에는 하나만 |
| 새 앱 | NationQuiz는 나라 이름, WordQuiz는 뜻(또는 읽기). 같은 답으로 받아들일 수 있는 것을 같은 열쇠로 만듭니다. |

1. 정답의 열쇠를 먼저 「쓴 열쇠」에 넣습니다.
2. 후보를 섞어 차례로 보며, 열쇠가 이미 쓴 것이면 건너뛰고 3개를 고릅니다. 같은 ID도 건너뜁니다.
3. 후보가 모자라면 지금 풀 → 지금 범위 전체 → 앱 전체 순서로 넓혀 채웁니다(NameQuiz 방식). CharQuiz는 풀 안에서만 골라 보기가 4개보다 적을 수 있습니다.
4. 네 보기를 섞어 놓습니다.

## 채점

`calculateReviewState`가 한 번 답할 때마다 항목을 고칩니다.

| 경우 | 하는 일 |
| :--- | :--- |
| 모든 응답 | 푼 수 +1, 마지막으로 푼 때를 지금으로 |
| 응답이 5초 이상 | 5000ms로 잘라 기록만 넣고 끝. 단계는 바꾸지 않습니다. |
| 오답 | 오답 수 +1. **3번이 되면 단계 0**, 응답 기록을 비우고 승급 자격을 잃습니다. 오답의 응답 시간은 기록하지 않습니다. |
| 정답 | 응답 시간을 최근 10개 기록(고리 버퍼 `recentLatencies`)에 넣습니다. 연속 정답 3번마다 오답 수 −1 |
| 승급 자격 없음 | 단계 0인 새 항목만 첫 정답에 단계 1(해금) |
| 승급 자격 있음, 기록 10개 | 이번 응답이 평균 × 1.2보다 느리면 단계 −1, 아니면 +1(최대 8). 한 판에 한 번만 |

- 기록 모드(20문제·30초)도 같은 채점을 쓰되 해금된 항목만 고칩니다.
- 저장 필드: `domain, charId, stage, recentLatencies, latenciesIdx, outCnt, resetOutCnt, totalSolved, lastSessionTime, sessionStreak, updatedAt`. 승급 자격 같은 판 안의 표시는 저장하지 않습니다.
- 저장 위치: 기기의 localStorage(`{앱}_PROGRESS_CACHE_{uid}`)에 먼저 쓰고, Firestore `users/{uid}/progress/{범위}/chars/{문제ID}`에 한 번에 씁니다. 로그인하면 서버와 기기 중 `lastSessionTime`이 늦은 쪽을 남깁니다.

## Combo

학습 모드에서 정답을 **2번 이상 이어서** 맞히면 화면 가운데에 「N COMBO!」가 튀어 올랐다가 사라집니다(`components/combo-fx.js`).

| 항목 | 규칙 |
| :--- | :--- |
| 세는 법 | 이번 판의 답 기록(`sessionHistory`)을 끝에서부터 거슬러 이어진 정답 수(`getTrailingStreak`). 틀리면 0으로 끊깁니다. |
| 띄우는 때 | 학습 모드의 답 처리(`handleUserAnswer`)에서 정답일 때 `showCombo(이어진 수)`. 2 미만이면 띄우지 않습니다. |
| 모양 | 숫자(3rem)와 「COMBO!」. 분홍 글씨에 흰 그림자. 화면 가운데(위에서 42%), 누르기를 막지 않음(`pointer-events: none`) |
| 큰 Combo | 5, 10, 그리고 20 이상의 10의 배수(20, 30, 40…). 금색, 숫자 4.2rem, 끝에 ✨ |
| 움직임 | `@keyframes comboPop` 0.9초: 작게 나타나 튀어 오른 뒤 위로 떠오르며 사라짐. 새 Combo가 오면 앞의 것을 지웁니다. |
| 동작 줄이기 | `prefers-reduced-motion`이면 움직이지 않고 나타났다 흐려지기만 합니다(`comboFade`). |
| 모드 | **학습 모드에서만.** 기록 모드(20문제·30초)와 관전 모드에는 없습니다. |

- 같은 연속 정답을 판을 넘어 이어 세어 학습현황의 「최대 콤보」 기록으로 남깁니다([「설정·순위·학습현황」](#/sh-standard/quizapp-common-gui/rules/screens.md) 「콤보 기록」).
- 효과는 장식이라 `aria-hidden="true"`입니다. 화면 읽기 프로그램에 읽히지 않습니다.
- CSS는 `.combo-fx`, `.combo-big`, `.combo-count`, `.combo-word`, `.combo-spark`와 두 키프레임입니다. 두 앱에 같은 파일과 같은 CSS가 있습니다.

## 화면 요소

| 요소 | 규칙 |
| :--- | :--- |
| 문제 | 가운데에 크게. 소리 문제는 처음에 한 번 읽어 줍니다. |
| 보기 | 2×2 격자. 너무 빠른 연속 누르기(CharQuiz 150ms, NameQuiz 120ms 안)는 무시합니다. |
| 오답 표시 | 설정에서 고릅니다: 정답 표시와 소리 / 정답 표시만 / 무시(바로 다음 문제). 정답 보기를 약 1초 초록으로 보입니다. |
| 최근 5문제 | 맞힘·틀림을 작은 막대로 |
| 풀 배지 | 풀의 항목마다 단계 색 배지. 이번 판에 승급하면 굵은 초록 테두리, 승급 자격이 있으면 얇은 초록, 새 항목은 점선 |
| 💡 힌트 | 학습 모드에서만. 누르면 시간이 멈추고 힌트 목록이 열립니다([「힌트」](#/sh-standard/quizapp-common-gui/rules/hints.md)). |
| 일시정지·중단 | 헤더 가운데. 중단은 확인을 묻습니다. |

## 단축키

| 키 | 동작 |
| :--- | :--- |
| 4 · 5 · 1 · 2 (또는 A · S · Z · X) | 보기 왼쪽 위 · 오른쪽 위 · 왼쪽 아래 · 오른쪽 아래 |
| Space | 소리가 있는 앱은 다시 듣기, 없는 앱은 일시정지·재개 |
| ESC | 중단 확인 |

- 입력칸에 글을 쓰는 동안에는 단축키를 무시합니다.
- 설정의 단축키 표에서 키마다 주 키와 보조 키를 다시 정할 수 있습니다.
