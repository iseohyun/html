# 학습 결과

학습 모드가 끝나면 처음 화면으로 돌아오면서 「학습 결과」 창을 띄웁니다. 이번 판에 한 번이라도 나온 항목만 한 줄씩 나오고, 나온 항목이 없으면 창을 띄우지 않습니다. 창은 바깥이나 ✕를 누르면 닫힙니다.

## 표

| 글자 | 맞힘 | 응답속도(초) | 상태 |
| :--- | :--- | :--- | :--- |
| あ | 3 / 3 | 1.4 → 1.1 | 승급 |
| か | 2 / 3 | 0.9 → 1.2 | 강급후보 |
| さ | 1 / 1 | - → 1.6 | 새문자 |
| **총계** | **6 / 7** | **1.2 → 1.3** | |

| 열 | 값 |
| :--- | :--- |
| 글자 | 항목. NationQuiz는 「나라」, WordQuiz는 「단어」처럼 앱의 말로 바꿉니다. |
| 맞힘 | 이번 판에 맞힌 수 / 푼 수 |
| 응답속도 | 「이전 → 이번」. 각각 최근 10개 응답 기록의 평균을 초로, 소수 한 자리. 「이전」은 판을 시작할 때 찍어 둔 값, 기록이 없던 항목은 「-」 |
| 상태 | 아래 다섯 가지 중 하나 |
| 총계 | 맞힘은 합, 응답속도는 줄마다의 평균을 다시 평균(값이 없는 줄은 뺌) |

표 아래에 한 줄을 둡니다: 「응답속도는 최근 기록 평균입니다. 강급후보는 이번에 틀렸거나 전보다 느려진 글자입니다.」

## 상태

위에서부터 처음 맞는 하나를 고릅니다.

| 상태 | 조건 |
| :--- | :--- |
| 새문자 | 판을 시작할 때 기록이 없던 항목(`totalSolved == 0`). 앱에 따라 「새 단어」, 「새 나라」 |
| 승급 | 끝날 때 단계 > 시작할 때 단계 |
| 강급 | 끝날 때 단계 < 시작할 때 단계. 오답 3번으로 단계 0이 된 경우도 여기 |
| 강급후보 | 이번에 한 번이라도 틀렸거나, 이전·이번 응답속도가 둘 다 있고 이번이 더 느림 |
| 유지 | 그 밖 |

- 단계가 바뀌는 조건은 [「문제 화면」](#/sh-standard/quizapp-common-gui/rules/quiz.md)의 「채점」에 있습니다. 승급·강급은 복습 때가 된 항목이 응답 기록 10개를 채웠을 때만 일어나므로, 대부분의 줄은 「유지」나 「강급후보」입니다.
- 시작할 때의 단계·평균·기록 여부는 판을 시작할 때 풀의 항목마다 찍어 둡니다(`sessionStartSnapshot`).

## 그 뒤

결과 창을 띄운 다음 복습 알림 예약, 진도 저장, 학습 시간 저장, 학습 순위 등록이 이어집니다.

> 참조: CharQuiz에만 있습니다(`main.js`의 학습 결과 부분). NameQuiz에는 아직 없고, 질문 퀴즈의 해설 리포트만 있습니다.
